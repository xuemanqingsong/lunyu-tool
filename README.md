# 论语工具（时习 · 论语每日一签）

论语学习辅助小工具：每天摇一签，孔子送一句论语；先自己琢磨它与今天生活的关联，再看今日事例，做一件「今日一试」的小事。

> 论语是**素材**不是**答案**——用户带着场景学一句论语，不是让论语回答他的问题。

## 仓库结构

```
├── one/  full/  qian/     # workbuddy 在线三版（摇一摇主站）
├── qian_v2/               # 去签化日课版（待发布）
│   ├── index.html / style.css / app.js
│   └── data-qian-1/2/3.js # 506章全量（原文/白话/解读/线索/今日一试）
├── prototype/             # 原型 + 分享卡设计稿
├── 每日一签生成/           # 内容生成管线存档（写法规范+分批/合并脚本）
├── server.py              # Flask 服务端（/one/ /full/ /qian/ 路由 + 数据上报 API）
└── selftest.sh            # 本地起服务自测脚本
```

## 分支约定

| 分支 | 含义 |
|---|---|
| `main` | 永远等于线上运行版本，不直接改 |
| `dev` | 日常开发/内容清洗在这里做，本地 `selftest.sh` 通过后合并进 `main` |

## 日常流程

```bash
git checkout dev          # 切到开发分支
# …改代码/清洗内容…
git add -A && git commit -m "说清楚改了什么、为什么"
bash selftest.sh          # 本地自测
git checkout main && git merge dev && git push   # 合并并推送
git checkout dev          # 回到 dev 继续
```

运行数据（`*/data/*.jsonl` 摇签/查询/反馈记录）不进版本库，已在 `.gitignore` 排除。
