# 论语小工具 v2 · 核心意群覆盖 · 返工标准

> 2026-09-21 覆盖排查完成后制定。返工对象 = 45 章被诊断出覆盖缺口的章。
> 原则（号主确立）：**每一个核心意群都要有一个对应的情境和每日行动；核心意群多于 3 个时，情境和每日行动也都可以超过 3 个，与核心意群的数目一致。**

---

## 一、返工分三类

### A 类：数量不足（核心意群 > 3，但 scenes/practices 各只有 3 条）
- 把 scenes 和 practices **各自增加到与核心意群数一致**（4 意群 → 4 条，9 意群 → 9 条）。
- 新增的每条，对应一个当前没有任何条目的意群。
- 已有条目保持不动（除非与新增重复）。

### B 类：分布失衡（核心意群 ≤ 3，但某意群无任何情境或行动对应）
- 不改数量（保持 3 条），**改写 1-2 条**，让每个意群至少有一条对应。
- 被改写的条目是当前「落点重复」的那几条（两个条目对应同一意群的，保留更贴切的一条，另一条改成缺的意群）。

### C 类：讲解漏意群（insight 未实质提及某个核心意群）
- 在讲解中**补写**漏掉的意群（实质提及即可，不必逐字），保持讲解的自然衔接，不要生硬插入。

---

## 二、写作要求（沿用《标准_情境切片与今日行动.md》）

- **情境切片**：具体有画面的现代处境，半句话讲清，让人一眼认出「这就是我」；是处境不是道理；从本章出发。
- **今日行动**：今天就能做的一件小事，具体可执行，贴合本章。
- **禁 AI 套话**（众所周知/不禁让人深思/综上所述等）、**禁说教腔**、**禁空泛词**（迷茫/努力/成长/坚持等无画面撑的抽象词）。
- 新增条目与本章其他条目**互不重复**，与全库其他章的条目语义上不雷同。

---

## 三、讲解补写要求

- 补写的句子要融入讲解原有语气（讲解是平实、不套模板的现代白话）。
- 覆盖 = 实质提及该意群即可（同义转述也行），不需要逐字引原文。
- 补写后讲解仍然通顺、不啰嗦（长度大致保持原有水平或略增）。

---

## 四、输出格式

对每一章，输出修改后的完整字段（只输出你改动的章，未改动的字段原样带回）：

```json
{
  "id": 5,
  "scenes": ["……", "……", "……", "……"],
  "practices": ["……", "……", "……", "……"],
  "insight": "……"
}
```

- scenes/practices 的最终条数 = 该章核心意群数（A类）或 3 条（B类）。
- insight 只在 C 类章输出（B/A 类章若 insight 没漏就不输出 insight 字段）。
- 必须用 python 读入输入文件、逐章分析后写出 JSON（utf-8、ensure_ascii=False）。
