## 原文疑点（供主代理统一处理，本批未改 text）

- id 1 学而篇「学而时习之」章：**翻译原只覆盖首句**，与「白话必须覆盖当前整段原文」冲突，本批已补全为三句全译。请知悉。
- id 2 学而篇「有子曰」章：同样存在**节译装全译**问题（原只译「君子务本」两句），本批已补全。另「为仁之本与」译文作「仁的根本吧」表推测语气，可接受。
- id 4 学而篇「曾子曰」章：原文开头作「曾吾日三省吾身」，**通行本为「曾子曰：吾日三省吾身」**，此处疑似漏「子曰：」二字。建议勘误为「曾子曰：吾日三省吾身」，text 待主代理核对上游原文。
- id 7 学而篇「子夏曰」章：原文结尾作「吾必谓之学已矣」，**通行本作「吾必谓之学矣」**（或「学已矣」有版本差异）。「已矣」连用存疑，记录待校，不改 text。
- id 8 学而篇「君子不重」章：原文「主忠信，无友不如己者」中「无友不如己者」后世多释为「不与不如自己的人交朋友」，但历来有争议（有解作「不要结交与自己志向不同的人」）。译文采用通行解释，不武断。
- id 9 学而篇「曾愼终追远」章：原文作「曾愼终追远」，**通行本为「曾子曰：慎终追远」**，此处漏「子曰：」且「愼」为「慎」异体。建议勘误「曾子曰：慎终追远」，text 待主代理核对。
- id 10 学而篇「子禽问于子贡」章：原文内层引号错乱（子贡语「夫子温良恭俭让以得之」前亦用「」），译文已按语义正确归属「子贡」；标点/引号建议上游统一。
- id 15 学而篇「子贡曰贫而无谄」章：原文结尾作「未若贫而乐」，**通行本为「未若贫而乐，富而好礼者也」**，明显截断。本批译文按通行本补足语义（「富有却谦虚好礼」），text 待主代理核对是否漏句。
