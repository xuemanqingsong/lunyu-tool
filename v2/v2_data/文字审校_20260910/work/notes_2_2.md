## 值得关注的疑点

1. **id 131 text 字段含非原文内容**：`text` 里附了一段「注解：「女有「汝、你的意思。本句文意是……」」，疑为数据导入时误把注释并入正文，与 id/theme/source/text 不变的要求冲突。建议主代理核对原始数据，如确为注释应移出 text，但按纪律本块不改 text。
2. **id 119 与 id 130 均漏译开头**：119 漏「已矣乎！」；130 漏整句「非不说子之道，力不足也」（冉求的话），已补全。提醒主代理：本库可能存在批量「节译装全译」问题，其他批次的「吾未见……」类开头叹词章可重点核查。
3. **id 133 insight 原稿史实错误**：「打了胜仗、救了大家」——原文为败退时殿后（「奔而殿」），已改。另此章 source 标「雍也篇」，确认无误。
4. **id 142 语境核对**：「齐一变，至于鲁；鲁一变，至于道」是孔子论治国之评（齐急功近利，鲁存礼乐传统），非泛论个人目标。原 insight 完全当作个人成长讲，略失原文语境，已补；同类「政治评论章」建议各批注意。
