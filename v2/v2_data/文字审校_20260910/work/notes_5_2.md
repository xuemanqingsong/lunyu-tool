## 重点疑点

1. **id 371「患其不能也」的释义方向**（已改译，仍建议主代理复核）：通行解释为「只怕自己没有才能」（不患人不己知，患己不能），多数注本（杨伯峻、钱穆）持此解。原 input 译作「怕的是我不了解别人」与通行解释相反，疑为串解。已按通行解改，若号主取别解请统一。
2. **id 381「末之难矣」译法**：通行解为孔子叹荷蒉者说得果决、「难以反驳/无以为难」（朱熹：末，无也；言其莫能难之），非「要做到很难」。原 input 译「可要真做到，就没这么容易了」为误读。已按通行解改，建议统一。
3. **id 387 text 有缺损**：text 从「衞灵公问陈」到「小人穷斯滥矣」，其中缺「子路愠见曰：『君子亦有穷乎？』」与孔子答之间的衔接（答语无「孔子对曰」字样），且开头「衞灵公问陈于孔子」一句后缺孔子答话的连接。文字本身与通行本一致处已核对，「君子固穷，小人穷斯滥矣」前疑漏「子曰」字样，属原文标点/脱字疑点，只记录不改 text。
4. **id 376 text 说话者辨识**：「莫我知也夫！」旧注为孔子叹（多数注本），子贡问「何为其莫知子也」后孔子答「不怨天……其天乎」。原 input translation 只译中间一句且标为孔子自述，已改为完整对话，说话者按通行本处理。
5. **id 395**：原 text 后半「居是邦也，事其大夫之贤者，友其士之仁者」是本句重心（为仁之法），原稿 scenes/translation/insight 全漏，已补全。
