## 疑点（待主代理统一处理，未改 text）

1. **id 148 与 id 158 同类病灶（重要）**：两章的 translation 都被写成「节译装全译」——id 148 只剩末段「己欲立而立人，己欲达而达人」，id 158 只剩「用之则行，舍之则藏」，均漏掉了章内前半或后半的整段内容。且 148 的 insight 被讲成博弈论/信用网络（工具腔），158 的 insight 整章讲成「失业者的解药」、漏掉「暴虎冯河」这一关键转折。疑似同类生成失误，建议排查全库「长文多对话章」的 translation 与 insight 是否也有截断或串章。
2. **id 154 原文「狎于德」**：输入 text 作「狎于德」，通行本（如《论语译注》）多作「据于德」。「狎」或为古今本异文/录入差异，译文按通行义「以德行为依据」处理；不改 text，建议主代理核对底稿。
3. **id 156 原文截断**：text 止于「擧一隅」，缺下半句「不以三隅反，则不复也」；translation 已意补出「不能由此推知另外三个墙角，就不再教他了」，与通行本一致，应系底稿截断，建议核对。
4. **id 159 translation「执鞭之士」**：意译为「做市场的守门卒」。「执鞭」有「驾车执鞭之役/市场守门小吏」两说，通行多解为「驾车的贱役」；现译文取「守门卒」一说，若需统一建议按通行本改为「给人家赶车」类译法。insight 未涉及该细节，不受影响。
5. **id 146「子见南子」史实**：南子为卫灵公夫人、名声有争议，insight 称孔子见她「出于礼节」属通行说法，未粉饰也未过度揣测，保留。
6. **id 161「三月不知肉味」**：现 insight 保留了原稿「心流」的说法，作为现代对应，属谨慎延伸，未作事实断言。
