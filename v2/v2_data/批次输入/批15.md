- 讲解（insight）：使者的回答妙极了：不说我们先生很忙、事业很好，而说他想减少自己的过错，还没做到。这句既真实又见境界——一个五十岁还想寡过的人，是有修行的。孔子连夸两声使乎，是欣赏这回答的真诚。对此刻的我有什么用：别把忙当成就，真正值得说的事，是你最近在改什么毛病、长什么本事。
- 现有情境（scene，供参考风格，可改可不改）：当你被问最近在忙什么，一时想不出一个能说出口的答案的时候。
- 现有今日行动（practice，供参考风格）：今天写下想减掉的一个毛病，配一条今晚就能动的小改法。

### id 366（《论语·宪问篇》| 标签：边界、职场、责任、分寸）
- 原文：不在其位，不谋其政。
- 白话：孔子说：不在那个职位上，就不要去谋划那个职位的政务。
- 讲解（insight）：这句常被当成事不关己，其实孔子是说：每个人的精力和责任都有限，做好分内的事，比到处插手更有价值。操心不在自己位置上的事，往往既帮不上忙，还搅乱秩序。今天很多人的累，一半来自干了别人的活、操了别人的心。对此刻的我有什么用：把越界的操心收回来，专注自己那一摊，反而更被尊重。
- 现有情境（scene，供参考风格，可改可不改）：当你忍不住去操心别人的岗位、别人的决定，却发现越界了不讨好、自己还累的时候。
- 现有今日行动（practice，供参考风格）：今天收回一次伸过界的手，只把自己那摊事做扎实。

### id 367（《论语·宪问篇》| 标签：边界、专注、职场、本分）
- 原文：曾君子思不出其位。
- 白话：曾子说：君子的思考，不超出自己的位置和本分。
- 讲解（insight）：曾子补了一句更往内的：思不出其位——连想，都别想过头。操心不在你位置上的人，是拿别人的课题折磨自己。今天焦虑的一大来源，就是想太多管不着的事。管好自己的位、守住自己的本分，想该想的，做该做的，心就安定下来。对此刻的我有什么用：给思考划个边界，你的睡眠和心情会明显好起来。
- 现有情境（scene，供参考风格，可改可不改）：当你睡前脑子里全是别人的事、单位的事、甚至不相干的事，越想越睡不着的时候。
- 现有今日行动（practice，供参考风格）：今晚睡前把这份名单写下来，划掉使不上力的，只留一件能动的。

### id 368（《论语·宪问篇》| 标签：言行、诚信、承诺、兑现、面子）
- 原文：君子耻其言而过其行。
- 白话：君子以说得多、做得少为耻。
- 讲解（insight）：透支承诺是这个时代最便宜也最贵的社交货币——便宜在于张口就来，贵在于信用破产只需几次。孔子的记账方式很简单：言是支出，行是收入，支出大于收入即为耻。扛不住面子答应了做不到的事，本质是把别人的期待当成了即时变现的工具，利息是你的人格。承诺前多算一步：这件事我确定能交付吗？宁可当场显得为难，不要事后被人失望。
- 现有情境（scene，供参考风格，可改可不改）：答应了却办不到、面子先行的时候
- 现有今日行动（practice，供参考风格）：今天把没兑现的承诺列成清单，挑一件先给人一个交代。

### id 369（《论语·宪问篇》| 标签：智慧、仁爱、勇气、心态、修养、纠结）
- 原文：君子道者三，我无能焉：仁者不忧，知者不惑，勇者不惧。子贡曰：「夫子自道也！
- 白话：孔子说：“君子之道有三条，我一条也没做到：有仁德的人不忧愁，有智慧的人不迷惑，有勇气的人不畏惧。”子贡说：“这正是老师对自己的写照啊！”
- 讲解（insight）：仁、智、勇，其实是面对问题的三种能力：仁让人心里安稳，不为得失忧；智让人看事清楚，不被表象牵走；勇让人该动手时不缩着。多数人的内耗，不是问题太大，而是三样暂时缺位——要么太在意结果，要么没想透，要么不敢面对。对此刻的我，可拿它当自检清单：正在忧虑时，是心不安，还是没看透，还是没胆量？对症补上那一条，人就松了。
- 现有情境（scene，供参考风格，可改可不改）：在深夜反复盘算一件事，既担心又拿不定主意，越想越睡不着的时候。
- 现有今日行动（practice，供参考风格）：今天先做那件拖得最久的小事，用行动把'勇'补上一块。

### id 370（《论语·宪问篇》| 标签：比较、评价他人、自省、专注、宽容）
- 原文：子贡方人。赐也，贤乎哉？夫我则不暇！
- 白话：子贡喜欢议论别人的长短。孔子说：“赐啊，你就那么贤良吗？我可没有闲工夫去评论别人。”
- 讲解（insight）：评论别人是最省力的消遣，也最容易上瘾。子贡爱“方人”，就是对人评头论足，孔子一句话点醒：与其花时间挑别人的对错，不如把这点精力收回来。对此刻的我，点评别人既改不了对方，也白白消耗自己。把“他怎么这样”换成“我该怎样”，关注点一转，时间就省出来了。不是不能判断人，而是别让评价成为习惯性的注意力出口。
- 现有情境（scene，供参考风格，可改可不改）：刷到同事或朋友的动态，忍不住想评头论足几句的时候。
- 现有今日行动（practice，供参考风格）：今天想说某人长短时先憋住，把话写下来，晚上回看值不值。

### id 371（《论语·宪问篇》| 标签：能力、成长、被理解、自信、学习）
- 原文：不患人之不己知，患其不能也。
- 白话：不怕别人不了解我，怕的是我不了解别人。
- 讲解（insight）：被误解的痛苦让人只盯着「人不己知」，孔子把镜头调转：你懂别人吗？多数「没人理解我」，翻过来是「我也没花力气理解过任何人」。知人是一项硬技能：他为什么这么说、他在怕什么、他真正想要什么——把这套分析用在别人身上，你会发现社交的钥匙一直插在锁上。先变成知人者，再谈被知。懂别人的人，从来不缺懂他的人。
- 现有情境（scene，供参考风格，可改可不改）：觉得没人懂你、社交受挫的时候
- 现有今日行动（practice，供参考风格）：今天挑一场对话，把目标倒过来：先听明白对方，不急着被明白。

### id 372（《论语·宪问篇》| 标签：识人、信任、明察、判断、边界）
- 原文：不逆诈，不亿不信，抑亦先觉者，是贤乎！
- 白话：孔子说：“不预先猜测别人会欺骗，不凭空怀疑别人不诚信，但遇事又能及早察觉真相，这样的人才算高明吧！”
- 讲解（insight）：这里讲的是信任与警觉的平衡：既不预设恶意，也不是傻乎乎全信，真有问题也能先察觉。现实中很多人走了两个极端——要么习惯性怀疑，把关系处得紧张；要么一味天真，吃了亏才后知后觉。对此刻的我，可以练“先给诚意，留个心眼”：平时不去猜疑，遇到关键节点、涉及利益处，核实一下就行。既保全关系，也守住自己。
- 现有情境（scene，供参考风格，可改可不改）：跟人打交道前先预设对方别有用心，结果自己越来越累的时候。
- 现有今日行动（practice，供参考风格）：今天先按善意理解一个人，但涉及钱和承诺的事当面核实一遍。

### id 373（《论语·宪问篇》| 标签：坚持、理想、固执、原则、被误解）
- 原文：微生亩谓孔丘，何为是栖栖者与？无乃为佞乎？孔非敢为佞也，疾固也。
- 白话：微生亩对孔子说：“丘啊，你为什么这样忙忙碌碌到处奔走？莫不是要逞口才、讨好别人吧？”孔子说：“我不敢逞口才，我是痛恨那种顽固不化、故步自封的状态。”
- 讲解（insight）：坚持自己认为对的事，常常会被误解。微生亩觉得孔子到处跑是耍嘴皮子，孔子说不是，是看不得有人抱残守缺才要行动。对此刻的我，被质疑“你图什么”时，不必急着证明自己，也无须因误解停下。只要清楚自己为什么在做，别人的评价就当背景音。真正要留意的反而是自己：别在不知不觉里变成那种守着旧习惯、拒绝改变的人。
- 现有情境（scene，供参考风格，可改可不改）：你明明在坚持一件正事，却被旁人看成“折腾”“出风头”的时候。
- 现有今日行动（practice，供参考风格）：今天用一句话写下你坚持这件事的理由，放在看得见的地方。

### id 374（《论语·宪问篇》| 标签：品德、能力、本质、判断、价值）
- 原文：骥不称其力，称其德也。
- 白话：孔子说：“千里马，人们称赞的不是它的力气，而是它的品性。”
- 讲解（insight）：千里马能日行千里，可真正让人敬重的，是它靠得住的那部分品性。能力强只是入场券，走得长不远，看的是稳不稳、靠不靠谱、有没有分寸。现实中见过太多“能人翻车”——不是栽在能力上，是栽在德行上。对此刻的我，与其拼命刷能力值，不如同步修“可靠”这条：答应的事做到，急时不乱来，对下不倨傲。这些看不见的分数，才是别人真正给你打的。
- 现有情境（scene，供参考风格，可改可不改）：看到一个能力很强但口碑很差的人，渐渐被众人疏远的时候。
- 现有今日行动（practice，供参考风格）：今天把答应人的事全部记下来，做完一件勾一件。

### id 375（《论语·宪问篇》| 标签：原谅、公平、原则、报复、道德、记仇）
- 原文：或曰：「以德报怨，何如？何以报德？以直报怨，以德报德。
- 白话：有人问：“用恩德来回报怨恨，怎么样？”孔子说：“那用什么来回报恩德呢？应该用正直来回应怨恨，用恩德来回报恩德。”
- 讲解（insight）：“以德报怨”听着大度，孔子却泼了盆冷水：对坏人一味示好，好人反而寒心。他主张“以直报怨”——不报复，也不讨好，用对事不对人的态度把问题处理掉。对此刻的我，受委屈后不必强装宽宏大量，也不必憋着报复。把情绪放下，该说清的说清，该走流程的走流程，让对方知道你的边界就好。这样既没把自己憋出内伤，也没把关系彻底烧掉。

- 现有今日行动（practice，供参考风格）：今天对亏待你的人只谈事不动气，把你的底线明确说一次。
