- 现有情境（scene，供参考风格，可改可不改）：和父母、长辈说话，或临到重要告别，想说点真心话又不知从何说起的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天对最亲的人说话时放慢语速，把音量和态度都调软一度。

### id 190（《论语·泰伯篇》| 标签：谦虚、求知、包容、受屈、成长）
- 原文：曾以能问于不能，以多问于寡，有若无，实若虚，犯而不校。昔者吾友，尝从事于斯矣。
- 白话：有才能的人却向没才能的人请教，学识多的人却向学识少的人请教，有学问像没有一样，内心充实却像虚空一样，被人冒犯也不计较。从前我的朋友，曾经在这上面下过功夫。
- 讲解（insight）：最有底气的人，恰恰是最敢说“我不懂”的人。懂得越多，越清楚自己不知道的更多，所以能毫无负担地向不如自己“资历”的人讨教，听进不同意见。真正伤人的从来不是承认无知，而是用虚张声势掩盖无知。今天与其守住“我比你会”的姿势，不如承认“这里你懂的比我多”，对方会因此更愿意掏心窝子，你也会少走很多弯路。
- 现有情境（scene，供参考风格，可改可不改）：当你是团队里的老手、却想放下面子向刚入行的新人请教的时候。
- 现有今日行动（practice，供参考风格）：今天向一位新人或晚辈，请教一个你真心想学的问题。

### id 191（《论语·泰伯篇》| 标签：责任、担当、信任、忠诚、使命）
- 原文：曾可以托六尺之孤，可以寄百里之命，临大节而不可夺也。君子人与？君子人也！
- 白话：可以把年幼的孤儿托付给他，可以把一个地方的命运托付给他，面临生死大节也不会犹豫。这样的人是君子吗？这样的人就是君子啊！
- 讲解（insight）：这句话把“可靠”说到了底：不只是靠谱地办成一件小事，而是在重压、风险和诱惑面前都不掉链子。现代社会里，能把孩子托付、能把一笔大钱托付、能把一个项目关键节点托付的人，永远是稀缺资源。判断一个人值不值得托付，别看他顺风顺水时多客气，要看他压力大、没人看着时怎么做事。你也可以用这个标准问问自己：别人敢不敢把重要的事交到我手里。
- 现有情境（scene，供参考风格，可改可不改）：当你必须把最重要的事交到一个人手里、在心里掂量他到底靠不靠得住的时候。
- 现有今日行动（practice，供参考风格）：今天接手要紧事时，把进展和风险如实同步，做那个让人放心的人。

### id 192（《论语·泰伯篇》| 标签：责任、使命、坚持、担当、信念、长期）
- 原文：曾士不可以不弘毅，任重而道远。仁以为己任，不亦重乎；死而后已，不亦远乎。
- 白话：有志之人不可以不宽宏坚毅，因为责任重大，路途遥远。
- 讲解（insight）：累到想撂挑子时，曾子这句话是清醒剂：先接受「任重道远」是设定，不是意外。路远不是你选错了路，而是所有值得走的路都远。「弘」是心胸要撑得开——装得下委屈和漫长；「毅」是腿要迈得稳——一步是一步。真正的坚韧不是咬牙硬扛的悲壮，而是知道自己为什么走在路上。想清楚「任」是什么，重就重得其所；没想清楚，一根稻草也压垮人。
- 现有情境（scene，供参考风格，可改可不改）：任务太重、路太长，撑不下去的时候
- 现有今日行动（practice，供参考风格）：今天把目标切成只剩下一步，走完这一步就停，攒着劲明天再走。

### id 193（《论语·泰伯篇》| 标签：成长、修养、学习、艺术、人格）
- 原文：兴于诗，立于礼，成于乐。
- 白话：用诗来激发心志，用礼来立身处世，用乐来完善人格。
- 讲解（insight）：这是古人给成长排的一条顺序：先被美好的东西点燃，再靠规则和习惯立住自己，最后被艺术和共鸣滋养完整。放到今天看，很像是先找到热爱，再学会自律和边界，最后活出从容。很多人卡在第二步——只有热情没有约束，或者只剩下规矩、早忘了为什么出发。提醒自己：光会拼不算立住，光懂规矩不算完整。顺序可以重新接上，任何时候都来得及。

### id 194（《论语·泰伯篇》| 标签：领导、管理、边界、智慧、原则）
- 原文：民可使由之，不可使知之。
- 白话：对于普通百姓，可以让他们照着做，不必让他们明白其中的道理。
- 讲解（insight）：这句历来争论很多，放在今天不必照单全收，它真正有价值的分寸是：很多事不是靠讲道理讲成的，而是先把规矩立好、让人照着走，在做的过程中慢慢体会。职场里最常见的内耗，就是事事都要先说服每一个人才肯动手。好的做法是抓大放小——大方向讲明白，操作层面先用统一规则跑起来，边做边让道理自己浮出来。

### id 195（《论语·泰伯篇》| 标签：贫穷、愤怒、情绪、原则、人际、风险）
- 原文：好勇疾贫，乱也。人而不仁，疾之已甚，乱也。
- 白话：喜好逞勇斗狠又痛恨自己贫穷，就会生乱。人没有仁爱之心，大家又把他恨得太厉害，也会逼出乱子。
- 讲解（insight）：这句话讲了两种容易失控的情形：一种是处境困顿又满心不平的人，容易被愤怒裹挟；另一种是身边的人毫无温情，把一个人逼到无处可退。它提醒的其实是“留余地”——对自己，别让怨气替你决定动作；对别人，别把人往绝路上逼。给处境差的人一条体面的出路，比说一百句大道理更能避免冲突。今天在快要失去耐心时，先停一下，想想对方缺的是什么。
- 现有情境（scene，供参考风格，可改可不改）：当你看到一段关系被挤到墙角、只剩下对抗情绪、眼看要爆的时候。
- 现有今日行动（practice，供参考风格）：今天给一个闹僵的人留个台阶，让这事还有转身的余地。

### id 196（《论语·泰伯篇》| 标签：骄傲、谦虚、才能、格局、人际）
- 原文：如有周公之才之美，使骄且吝，其余不足观也已！
- 白话：即使有周公那样出众的才能，如果骄傲又吝啬，其余的地方也就不值得看了。
- 讲解（insight）：这是对“能力崇拜”的一盆冷水：才能再大，只要占了“骄”和“吝”这两条，前面都白搭。骄，是觉得自己天下第一，听不进任何反馈；吝，是把自己的本事和资源攥得死死的，不愿分享也不愿付出。这样的人能力强，却很难共事，也很难走远。反过来也是提醒自己：真正让人愿意托付的，从来不只是你多能干，而是你能不能让人放心——不居功，也不算计。
- 现有情境（scene，供参考风格，可改可不改）：当你遇到一个能力很强、却因为骄傲或斤斤计较让人不舒服的人的时候。
- 现有今日行动（practice，供参考风格）：今天把一件事的功劳当众分给协作者，说清每个人做了什么。

### id 197（《论语·泰伯篇》| 标签：学习、初心、坚持、意义、利益）
- 原文：三年学，不至于谷，不易得也。
- 白话：学了三年，还不把心思放在求取俸禄官职上，这样的人不容易遇到啊。
- 讲解（insight）：古人学三年还在意学问本身、不急着变现，被认为是很难得的品质。今天更难得：很多人学一样东西，第一反应是“这能涨工资吗、能换什么好处”，学三天没回报就弃了。可真正值钱的技能，几乎都要熬过一段没有回报的时光。不是反对你想着回报，而是别让“回报”成为学习的唯一理由——那样你撑不过枯燥期，也学不到深处。先不问值不值，学扎实了，价值自然会来。
- 现有情境（scene，供参考风格，可改可不改）：当周围人都在为短期回报着急、而你还能沉下心学点暂时用不上的东西的时候。

### id 198（《论语·泰伯篇》| 标签：信念、原则、环境、选择、底线、价值观）
- 原文：笃信好学，守死善道。危邦不入，乱邦不居。天下有道则见，无道则隐。邦有道，贫且贱焉，耻也；邦无道，富且贵焉，耻也。

- 现有今日行动（practice，供参考风格）：今天为最看重的一个信念找一篇反方观点，认真读完它。

### id 199（《论语·泰伯篇》| 标签：边界、职场、责任、分寸、管理）
- 原文：不在其位，不谋其政。

- 现有今日行动（practice，供参考风格）：今天挑一次越界的关心收住，改成只提一句，不替他做主。
