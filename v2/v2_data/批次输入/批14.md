- 讲解（insight）：原宪以为克制自己就是仁，孔子却说：能克制确实难得，但那还只是管住，不算仁。仁不只是把不好的念头压下去，更是一种活得开阔的状态。这提醒今天的我们：天天咬牙压抑自己，不是修养的终点，反而可能憋出问题。对此刻的我有什么用：别把忍住当修行，真正的功课是让那些念头本来就轻，而不是靠硬扛。
- 现有情境（scene，供参考风格，可改可不改）：当你辛苦压住自己的脾气和欲望，以为这就叫修到位了的时候。
- 现有今日行动（practice，供参考风格）：今天挑一次憋着没说的话，换个方式好好把它讲出来。

### id 342（《论语·宪问篇》| 标签：安逸、舒适区、奋斗、改变、勇气、目标、失业）
- 原文：士而怀居，不足以为士矣！
- 白话：留恋安逸窝的人，不值得称为士。
- 讲解（insight）：孔子对「怀居」的否定毫不留情：把舒适当成目的的人，自动退出有志者序列。这不是歌颂苦难，而是指出一个残酷事实——舒适区不保温：你以为在守，其实在折旧。温水的问题不是烫，是它让你误以为水温恒定，直到行业变动、年龄增长、能力贬值同时到账。离开舒适区不等于鲁莽跳崖，而是保持「随时能走」的状态：定期面试、持续学习、留一笔「自由基金」。

### id 343（《论语·宪问篇》| 标签：正直、谨慎、原则、环境、表达）
- 原文：邦有道，危言危行；邦无道，危行言孙。
- 白话：孔子说：国家政治清明，说话和行事都正直；国家政治混乱，行为仍要正直，但说话要谦逊谨慎。
- 讲解（insight）：孔子给了一条极有分寸的活法：行为在任何时候都别弯，这是底线；但言语的分寸要看环境——环境清朗可以直说，环境浑浊话要软一点，不是圆滑，是自保。今天也一样：原则可以一寸不让，但表达的方式可以灵活。对此刻的我有什么用：守住行为上的正直，同时学会在复杂环境里用更稳妥的话把态度讲清楚。

### id 344（《论语·宪问篇》| 标签：本质、德才、言行、判断、勇敢）
- 原文：有德者必有言，有言者不必有德。仁者必有勇，勇者不必有仁。
- 白话：孔子说：有德行的人一定能说出有见地的话，但能说会道的人未必有德行。仁德的人一定有勇气，但勇敢的人未必有仁德。
- 讲解（insight）：孔子给了两个不对等的推导：德能带出言，言却带不出德；仁能带出勇，勇却带不出仁。说白了，真本事会自然流露出来，但外表的东西（会说话、够猛）不保证里面有货。今天尤其要当心那些口才极好、气势很足的人，越漂亮的话越要往里面看一看。对此刻的我有什么用：看人别被会说和敢冲带走，往德行和动机里多看一眼。
- 现有情境（scene，供参考风格，可改可不改）：当你想判断一个人到底有没有真东西，而不是只会讲的时候。
- 现有今日行动（practice，供参考风格）：今天对一位很会说的说服者，多问一句'这件事的实据是什么'。

### id 345（《论语·宪问篇》| 标签：谦逊、尚德、价值观、力量、判断）
- 原文：南宫适问于孔羿善射，奡荡舟，俱不得其死然。禹稷躬稼而有天下。夫子不答。南宫适出，君子哉若人！尙德哉若人！
- 白话：南宫适问孔子：羿擅长射箭，奡能陆地行舟，都不得好死。禹和稷亲自种地，却得了天下。孔子没回答。南宫适走后，孔子说：这人是君子啊！这人崇尚德行啊！
- 讲解（insight）：南宫适拿两类人对比：靠武力、靠蛮力的羿和奡都不得善终，勤恳务实的禹和稷反而得到天下。他问完就明白了，孔子不答是认可。这句话在今天像一剂清醒药：别只盯着那些靠投机、靠强势迅速得势的人，时间站在踏实做事这一边。对此刻的我有什么用：当你怀疑老实是不是吃亏，想想长期账，做实的赢在最后。
- 现有情境（scene，供参考风格，可改可不改）：当你看多了靠蛮力、靠手段起家又迅速败落的人，开始重新掂量老实做事的价值的时候。
- 现有今日行动（practice，供参考风格）：今天把一件最该做实的活从头到尾做扎实，不赶任何交差。

### id 346（《论语·宪问篇》| 标签：仁、判断、格局、人性）
- 原文：君子而不仁者有矣夫！未有小人而仁者也！
- 白话：孔子说：君子之中不仁的人是有的，但小人之中从来没有仁德的人。
- 讲解（insight）：孔子的意思是：君子也会有不仁的时候，所以别用一次失德就否定整个人，也别指望谁永远完美；但心里没有底线的人里是长不出仁的。这句话教我们看人别贴死成见，但也别心存幻想。对此刻的我有什么用：允许好人有瑕疵，同时看清楚本质——一次失误可原谅，一贯无底线要远离。
- 现有情境（scene，供参考风格，可改可不改）：当你看到一个口碑不错的人做出不地道的事，或者反过来看低一个人时的时候。
- 现有今日行动（practice，供参考风格）：今天重想一个让你失望的人，把'失误'和'人品'分开记两栏。

### id 347（《论语·宪问篇》| 标签：教育、爱、责任、严格、付出）
- 原文：爱之，能勿劳乎？忠焉，能勿诲乎？
- 白话：孔子说：真正爱一个人，能不为他操劳吗？真正忠于一个人，能不对他尽心劝告吗？
- 讲解（insight）：爱不是口头上的，是肯为对方劳心费力；忠也不是顺着来，是该说的还是要说。今天有个误区：以为爱就是让他舒服，忠就是不得罪人。结果该管的不管，该劝的不劝。对真正在乎的人，你得肯花力气、肯担风险。对此刻的我有什么用：别把不管不问当成体面，对在意的人，该操的心、该说的话，一项都别省。
- 现有情境（scene，供参考风格，可改可不改）：当你面对真正在意的人，纠结该管不管、该说不说的时候。
- 现有今日行动（practice，供参考风格）：今天把那句存了很久的真心话，好好说给你在意的人听。

### id 348（《论语·宪问篇》| 标签：合作、团队、严谨、方法、管理）
- 原文：为命，裨谌草创之，世叔讨论之，行人子羽修饰之，东里子产润色之。

### id 350（《论语·宪问篇》| 标签：贫穷、心态、抱怨、攀比、金钱）
- 原文：贫而无怨，难；富而无骄，易。

- 现有今日行动（practice，供参考风格）：今天给自己十分钟尽情诉苦，时间一到就去做一件具体的小事。
