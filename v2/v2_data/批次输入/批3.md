- 讲解（insight）：位置越高，越不能只摆姿态。身居上位不宽容，行礼不走心，面对丧事不掉泪——这些仪式只剩空壳，孔子说实在没眼瞧。他说的是态度本身的穿透力：你心里有没有那回事，别人隔着十米都闻得出来。带团队、做父母、当朋友都一样，装出来的尊重比不做更伤。今天检查自己一件例行公事，把心放进去做一次。
- 现有情境（scene，供参考风格，可改可不改）：当领导嘴上说着"有事找我"、眼神却写着"别烦我"，让你觉得他全是走过场的时候。
- 现有今日行动（practice，供参考风格）：今天检查自己一件走过场的日常，把心放进去重做一次，感受差别。

### id 67（《论语·里仁篇》| 标签：环境、圈子、选择、成长、习惯）
- 原文：里仁为美。择不处仁，焉得知？
- 白话：住在有仁德的地方才好。选择住处不选在有仁风的地方，怎么能算聪明呢？
- 讲解（insight）：「孟母三迁」的理论出处就在这：孔子认为选择环境的智慧，高于在坏环境里硬扛的意志。现代行为科学证实了这一点——意志力是消耗品，环境是常开的风：你在赌场里戒赌和在图书馆里戒刷手机，难度天差地别。与其天天消耗意志对抗诱惑，不如一次性搬迁到诱惑稀薄的地带：换工位、换群聊、换作息、换掉常去的酒局。人拼不过环境，但可以选择环境。
- 现有情境（scene，供参考风格，可改可不改）：低估环境、硬扛意志力的时候
- 现有今日行动（practice，供参考风格）：今天做一次小搬家：把最耽误你的那个东西挪出你常待的地方。

### id 68（《论语·里仁篇》| 标签：心态、价值观、原则、成长、逆境）
- 原文：不仁者，不可以久处约，不可以长处乐。仁者安仁，知者利仁。
- 白话：孔子说："没有仁德的人，不能长久地身处困顿，也不能长久地享受安乐。有仁德的人安于仁，聪明的人懂得利用仁。"
- 讲解（insight）：没有内在根基的人，穷久了会怨，富久了会飘，两头都待不住。真正稳的，是不管身处穷富，心里都有一件不被环境牵动的东西。现代人兜兜转转，加班到垮、躺平到空，多半是缺这个安的支点。聪明人把仁当工具，仁者把仁当家。今天不用想太远，先找出那样东西：就算没了钱和认可，你还愿意继续做的事。
- 现有情境（scene，供参考风格，可改可不改）：当你在穷得发慌和闲得发慌之间来回摆荡，哪种状态都待不住的时候。
- 现有今日行动（practice，供参考风格）：今天找出一件没了钱和掌声也愿意继续做的事，为它留十分钟。

### id 69（《论语·里仁篇》| 标签：判断、原则、爱憎、价值观）
- 原文：惟仁者能好人，能恶人。
- 白话：孔子说："只有有仁德的人，才能恰当地喜爱人，也能恰当地厌恶人。"
- 讲解（insight）：我们的好恶大多不干净：因为对方有用而喜欢，因为对方碍事而讨厌。孔子的意思是，只有心里立得住的人，才能纯粹地爱一个人、恨一件事——爱与恨都看人品本身，不看它对我有没有好处。这不是冷酷，是清醒。今天可以试着把一个人从对我有用里摘出来，纯粹地看他是个怎样的人。
- 现有情境（scene，供参考风格，可改可不改）：当你发现自己喜欢一个人是因为他有用、讨厌一个人是因为他碍事的时候。
- 现有今日行动（practice，供参考风格）：今天挑一个人，不看他对你有没有用处，只为欣赏而发一条真诚的问候。

### id 70（《论语·里仁篇》| 标签：价值观、心态、原则）
- 原文：苟志于仁矣，无恶也。
- 白话：孔子说："如果一个人诚心立志于仁，就不会有恶行了。"
- 讲解（insight）：这句话不是许愿从此无恶，而是说方向定了，轨道就对了。一个人真心把做好人当作奔头，他的错就只是偏差，不是底色，随时能掰回来。现代人常在小事上反复自责，其实缺的不是完美，是那个大方向。先决定自己想成为哪种人，剩下的都是修正。今天给自己立一句方向，明天做砸了也不至于塌。
- 现有情境（scene，供参考风格，可改可不改）：当你因为一点小错反复自我攻击，怀疑自己是不是就这样了的时候。
- 现有今日行动（practice，供参考风格）：今天写下你想成为哪种人的一句话方向，往后错了只当偏差，不当定论。

### id 71（《论语·里仁篇》| 标签：金钱、原则、底线、价值观、选择）
- 原文：富与贵，是人之所欲也，不以其道得之，不处也。贫与贱，是人之所恶也；不以其道得之，不去也。君子去仁，恶乎成名？君子无终食之闲违仁，造次必于是，顚沛必于是。
- 白话：孔子说："财富和尊贵，是人人都想要的，但不用正当的方式得到它，就不接受。贫穷和卑贱，是人人都厌恶的，但不用正当的方式摆脱它，就不逃避。君子一旦离开了仁，还凭什么成就名声？君子连吃一顿饭的工夫都不会离开仁，仓促匆忙时如此，颠沛流离时也如此。"
- 讲解（insight）：想要好日子、怕过坏日子，这是人之常情，孔子不装圣人。难的是那道红线：好东西不能用脏手段拿，坏处境也不能用脏手段逃。更细的一层是连吃顿饭的工夫都不离开仁——底线不是大是大非才守，而是在每个普通瞬间不松手。现代人真正难的是当好处够大、理由够顺时还收得住。把红线提前写下来，别等到诱惑来了再临场发挥。
- 现有情境（scene，供参考风格，可改可不改）：当一份高薪但需要你睁一只眼闭一只眼的工作摆在你面前的时候。
- 现有今日行动（practice，供参考风格）：今天把你绝不越过的那道线写下来，别等事情上门再临时拿主意。

### id 72（《论语·里仁篇》| 标签：努力、价值观、信念、行动、分歧）
- 原文：我未见好仁者，恶不仁者。好仁者，无以尙之；恶不仁者，其为仁矣。不使不仁者加乎其身。有能一日用其力于仁矣乎？我未见力不足者！盖有之矣，我未之见也。
- 白话：孔子说："我没有见过真正喜爱仁、厌恶不仁的人。喜爱仁的人，没有比这更好的了；厌恶不仁的人，他行仁的方式，是不让不仁的事沾到自己身上。有没有人能花一天的力气用在仁上呢？我没见过力气不够的人！也许有吧，只是我没见到。"
- 讲解（insight）：孔子说他从没见过真肯在仁上用力的，还补了一句狠的：真去用力的人，从没听过谁力气不够。意思是多数人不是不能，是根本没打算花一整天试。我们常说我想变好，但没为它完整投入过一天。问题从来不是能力不足，是没当真。今天别立大目标，就挑一件小事，认真做满一天，晚上看看自己到底差在哪。
- 现有情境（scene，供参考风格，可改可不改）：当你嘴上说想改变，却发现自己连一整天都没为它认真过的时候。
- 现有今日行动（practice，供参考风格）：今天挑那件事试一次：不立目标、不宣布，就认真投入一整天，晚上看差距。

### id 73（《论语·里仁篇》| 标签：识人、判断、观察、成长、嫉妒）
- 原文：人之过也，各于其党。观过，斯知仁矣。
- 白话：孔子说："人的过错，各自顺着他的那一类人而来。观察一个人的过错，就知道他仁不仁了。"
- 讲解（insight）：人犯的错各有各的路数，看出一个人的错法，就看清了他是什么人。因为人总在自己最执着的地方失手：贪的栽在贪上，傲的栽在傲上。了解一个人，别看他顺风顺水的样子，看他摔倒时抓住什么。这条也照自己：你反复犯的那类错，就是你的盲区所在。今天观察一个人（包括自己）的错法，比听十句自我介绍都准。
- 现有情境（scene，供参考风格，可改可不改）：当你想判断一个人靠不靠谱，却又不知道该看哪里的时候。
- 现有今日行动（practice，供参考风格）：今天写下自己最常犯的那类错，倒推一句它来自哪个执念。

### id 74（《论语·里仁篇》| 标签：意义、信念、追求、价值观、嫉妒、记仇、原谅）
- 原文：朝闻道，夕死可矣！
- 白话：早晨明白了真理，就算当晚死去也值得。
- 讲解（insight）：这句话的重量常被低估：一个人可以为一件事的意义支付整个生命，说明「闻道」——真正弄明白自己为何而活——是人生最高级别的资产。反过来讲，很多人痛苦不是因为穷或忙，而是从未「闻道」：不知道自己信什么，于是什么都留不住。如果你现在对一切提不起劲，问题可能不是缺动力，是缺一个值得赴死的「道」。找到它，早晨和黄昏都会变得不一样。
- 现有情境（scene，供参考风格，可改可不改）：怀疑一切努力有没有意义的时候
- 现有今日行动（practice，供参考风格）：今天写下“如果只能保留一件事，我保留什么”，只要一个答案。

### id 75（《论语·里仁篇》| 标签：物欲、金钱、初心、价值观、面子）
- 原文：士志于道，而耻恶衣恶食者，未足与议也！
- 白话：有志于追求大道的人，却以穿得差、吃得差为耻，那就不值得与他讨论道了。
- 讲解（insight）：孔子的标准很高频地打在现代人身上：志向是道，注意力却全在衣食的段位上——这两种人生态度无法兼容。攀比消费的吊诡在于：它用「证明自己」的逻辑掏空你，等你攀上一级，上面永远还有一级。耻于「恶衣恶食」的人，其实志不在道，在观众的目光里。把评价权从路人手里收回来，是财务和精神同时止损的开始。
- 现有情境（scene，供参考风格，可改可不改）：被消费攀比裹挟、觉得处处不如人的时候
- 现有今日行动（practice，供参考风格）：今天做一次没人看的消费决定：只问实不实用，不问别人怎么看。
