- 原文：子谓公冶长，「可妻也；虽在缧絏
- 白话：孔子评价公冶长："可以把女儿嫁给他。他虽然被关在牢里，但那不是他的罪过。"于是把女儿嫁给了他。

- 原文：子贡问曰：「赐也何如？女器也。曰：「何器也？曰：「瑚琏也。

### id 97（《论语·公冶长篇》| 标签：沟通、表达、谦虚、职场、人际、转行）
- 原文：或曰：「雍也，仁而不佞。焉用佞？御人以口给，屡憎于人。不知其仁；焉用佞？
- 白话：有人说："冉雍有仁德，但口才不好。"孔子说："要口才干什么？靠一张利嘴去辩倒别人，常常招人厌恶。我不知道他仁不仁，但何必非要口才？"
- 讲解（insight）：这话不是反对会说话，是反对佞——靠一张利嘴把人怼到墙角、句句都要占上风。孔子说，靠嘴皮子压人，迟早把人得罪光；真有本事的人，嘴笨点也照样立得住。现代职场里，那种每次讨论都赢的人，往往也最没人愿意跟他合作。今天练习一次：明明能反驳，却选择不说，只回一句"有道理，我再想想"。看看天会不会塌。

- 现有今日行动（practice，供参考风格）：今天找一次明明能反驳的对话，只回“有道理，我再想想”，看天塌不塌。

### id 98（《论语·公冶长篇》| 标签：自信、职场、谦逊、判断、责任）
- 原文：子使漆雕开仕。对曰：「吾斯之未能信。子说。
- 白话：孔子让漆雕开去做官。漆雕开回答说："我对这个还不太有信心。"孔子听了很高兴。
- 讲解（insight）：孔子劝漆雕开去当官，他却说我对自己还没把握，孔子听了很高兴。高兴的不是他谦虚，是他诚实——知道自己的斤两，不肯装出信心去接一个接不住的位置。这种自量，比拍胸脯说我肯定行更靠得住，因为它不会把自己和别人都架到火上。今天面对一个机会，先诚实地问自己我真接得住吗，接不住就说出来，这不丢人。

### id 99（《论语·公冶长篇》| 标签：勇气、理想、信念、挫折、坚持）
- 原文：道不行，乘桴浮于海，从我者，其由与？子路闻之喜。由也，好勇过我，无所取材。

- 讲解（insight）：孔子半真半假说了句“道不行，乘桴浮于海”，子路立刻当真，乐坏了。孔子赶紧泼冷水：你也就剩个勇。这里面有成年人的幽默——心里想着退路，嘴上说说可以，其实清楚自己走不了，也清楚身边的拥趸未必是解决办法。对此刻的我有什么用：挫败时允许自己幻想一次“逃离”，但别把它当计划，情绪过去继续把事情往前推。
- 现有情境（scene，供参考风格，可改可不改）：当你理想受挫，想撂挑子远走高飞，还想着“至少有个死忠跟我走”的时候。
- 现有今日行动（practice，供参考风格）：今天把“想逃”写成三行，写完就撕，然后推手头的事往前半步。

### id 100（《论语·公冶长篇》| 标签：职场、能力、管理、判断、识人、迷茫、愧疚、内疚、自责）
- 原文：孟武伯问：「子路仁乎？不知也。又问，由也，千乘之国，可使治其赋也；不知其仁也。「求也何如？求也，千室之邑，百乘之家，可使为之宰也；不知其仁也。「赤也何如？赤也，束带立于朝，可使与宾客言也；不知其仁也。
- 白话：孟武伯问：子路有仁德吗？孔子说：不知道。又问，孔子说：仲由，在有千乘兵车的国家，可以让他治理军事，但我不知道他是否有仁德。又问冉求怎么样，孔子说：冉求，在有千户人家的城邑、百乘兵车的大夫之家，可以让他当总管，我不知道他是否有仁德。又问公西赤怎么样，孔子说：公西赤，穿上礼服立于朝堂，可以让他接待宾客，我不知道他是否有仁德。
- 讲解（insight）：孔子夸三个弟子各有所长——军事、政务、外交——但问到“仁”，一律说“不知道”。他不是否定他们，而是把“能力”和“为人”分开记账：能做多大事是能力账，心地如何是另一本账，不能混着报。今天识人用人都容易只看活儿、只看指标，孔子提醒那只是一半。对此刻的我有什么用：评价任何人，能力一句话、为人单独一句话，两本账分开记。
- 现有情境（scene，供参考风格，可改可不改）：当你被问“这人能力怎么样”，你只想得起他能干哪些事，却说不出他为人如何的时候。
- 现有今日行动（practice，供参考风格）：今天评价一位同事或朋友，分两句话说：一句能力，一句为人。
