- 讲解（insight）：孔子主张按颜回家境从简，学生却按对老师的敬意厚葬，结果还是厚葬了。他没有再强硬阻拦，只叹气“非我也，夫二三子也”——这不是我的意思。这里藏着处理关系的分寸：原则要有，也要承认有些事不是自己说了算；最伤心的时刻，还要为别人的善意留位置。坚持原则，不代表要否定别人的深情；分清哪些该坚持，哪些该接受。

### id 266（《论语·先进篇》| 标签：生命、生死、意义、务实、思考）
- 原文：季路问事鬼神。未能事人，焉能事鬼？「敢问死？曰：「未知生，焉知死？
- 白话：子路问怎样事奉生死两头。孔子说：'还没能侍奉好活着的人，怎么能侍奉离去的人呢？'子路又问：'请问死是怎么回事？'孔子说：'还没明白生，怎么能明白死？'
- 讲解（insight）：子路问生死两头，孔子两次把问题拉回生：“未能事人，焉能事鬼”“未知生，焉知死”。他不是回避大问题，而是指出顺序：把眼前能把握的人和事料理好，比纠缠够不着的问题更接近答案。现代人常一边焦虑寿命意义身后事，一边把今天过得稀里糊涂。生死想不明白，但把今天这顿饭、这段关系、这件工作做好，是每个人都能抓住的。
- 现有情境（scene，供参考风格，可改可不改）：深夜想到死亡、想到人生的意义，越想越慌，第二天却连手头那件麻烦事都还没处理好的时候。
- 现有今日行动（practice，供参考风格）：今天再焦虑大问题时，先做完一件具体的小事，再回头想它。

### id 268（《论语·先进篇》| 标签：保守、务实、改变、判断、谨慎）
- 原文：鲁人为长府。闵子骞曰：「仍旧贯，如之何？何必改作？夫人不言，言必有中。
- 白话：鲁国要改建收藏财货的长府。闵子骞说：'照老样子用下去不就行了？何必一定要改建呢？'孔子说：'这个人平时不说话，一开口就说到要害。'
- 讲解（insight）：大家都在主张改建时，闵子骞只问一句：旧库房还能用，何必改？孔子给他的评价是“言必有中”——平时惜字如金，一开口切中要害。这里有两层：少言让话有分量，因为他不是靠话多刷存在感；他说反主流的话却不被讨厌，因为他针对问题本身，不是针对人。现代职场里能替旧办法说句公道话很稀缺。说话先过脑，别为显得进取就轻易推翻还好的东西。

- 现有今日行动（practice，供参考风格）：今天在讨论重做之前，先列出现有做法站得住的三条理由，再决定开不开口。

### id 269（《论语·先进篇》| 标签：学习、阶段、成长、评价、谦逊）
- 原文：由之瑟，奚为于丘之门？门人不敬子路。由也升堂矣，未入于室也！
- 白话：孔子说：'子路的瑟，为什么在我这里弹？'学生们因此不敬子路。孔子说：'子路的水平，已经登堂了，只是还没入室罢了。'
- 讲解（insight）：孔子嫌子路的瑟声太粗放，批评了一句，学生们立刻跟着不敬子路。孔子马上补评：“由也升堂矣，未入于室也。”——他已经登堂，只差没入室。他批评的是水平，不是人品；差的是最后一层，不是全盘否定。现代场景里，领导一句批评，同事就边缘化那个人。这句示范了就事论事：批评完及时给出公允定位，不让一句负面评价变成对一个人的全盘盖章。
- 现有情境（scene，供参考风格，可改可不改）：老师当众批评了你一句，周围人开始看低你，你既委屈又没处说的时候。
- 现有今日行动（practice，供参考风格）：今天听到有人被一句批评盖棺定论时，补一句'TA也有做得好的部分'。

### id 270（《论语·先进篇》| 标签：平衡、适度、完美主义、判断、过犹不及）
- 原文：子贡问：「师与商也孰贤？师也过，商也不及。曰：「然则师愈与？过犹不及。
- 白话：做过头和做不够，是一样的（都不对）。
- 讲解（insight）：背景是子贡问：过头好还是不及好？孔子答：一样差。这句话专治两种病：一种以为「更努力总是对的」——加班到身体报警、鸡娃到亲子破裂、健身到受伤，都是「过」的学费；一种以为「差不多得了」——敷衍的健身、应付的陪伴、打折的诚信，都是「不及」的利息。难点在于「度」没有刻度，只能靠反馈校准：身体、关系、产出，哪个在报警，就往回调一点。中庸不是平庸，是恰到好处的火力。

### id 271（《论语·先进篇》| 标签：原则、金钱、管理、底线、正义）

- 现有今日行动（practice，供参考风格）：今天列出你工作中'给钱也不做'的三件事，存成自己的底线清单。
