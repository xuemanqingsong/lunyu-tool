- 讲解（insight）：子游嫌子夏只教学生洒扫应对这些“末节”，子夏反驳：教育要分步骤、看对象，就像草木各按品类生长，不能一刀切。对初学者，先把手边的小事做规矩，就是最好的起点；一上来就灌输“大道理”，反而悬空。对此刻的我，无论带新人还是学东西，这句都是方法论：别瞧不起“基本功”，也别指望一口吃成胖子。按阶段来，深的自然接得住。
- 现有情境（scene，供参考风格，可改可不改）：教人或带新人时，不知道是该先教“基本功”还是先讲“大道理”的时候，会想起这句。
- 现有今日行动（practice，供参考风格）：今天把那件“懒得练”的基本功捡起来，老老实实过一遍。

### id 491（《论语·子张篇》| 标签：学习、职场、成长、平衡、进步）
- 原文：子夏曰：「仕而优则学，学而优则仕。
- 白话：子夏说：“做官做得好、有余力了，就去学习；学习有余力了，就可以去做官，把学的用于做事。”
- 讲解（insight）：“仕而优则学”是防工作把人掏空——光干活不充电，人很快会变成重复的机器；“学而优则仕”是防学问变成死知识——学了一肚子，不去用、不与人打交道，等于白学。这八个字说的不是仕途，是“做事”和“学习”要互相喂养。对此刻的我，这是一条自我管理的小循环：忙时不忘留一块时间输入，闲时记得把学到的东西用出去，两头接上，人才不会枯。
- 现有情境（scene，供参考风格，可改可不改）：工作忙到没空学习，或者学了很久却没去用的时候，会想起这句。

- 原文：子游曰：「丧致乎哀而止。

- 讲解（insight）：子游五个字定了个度：哀，是丧礼的核心，够了就止。言外之意是，别用铺张的仪式、长久的折腾来证明孝心——真正的重点在有没有那份哀。对此刻的我，这话可以推广到所有“表达”上：形式是为真实的情感服务的，一旦形式开始喧宾夺主、变成表演，就该停下来。无论是悼念、道歉还是感谢，把心放对了，比把场面做足重要。

### id 493（《论语·子张篇》| 标签：评价、朋友、宽容、仁、判断）
- 原文：子游曰：「吾友张也，为难能也，然而未仁。
- 白话：子游说：“我的朋友子张，能做到的、气度才能，真是难能可贵，但还没有达到‘仁’的境界。”
- 讲解（insight）：子游这话的分量在公私分明：当着人的面他能夸子张“为难能也”，背后评价也不客套“然而未仁”。好朋友之间，不是一味捧，也不是背后拆台，而是能同时看得见对方的出色与不足，并且敢说出来。对此刻的我，这提醒的是“怎样才算真为朋友好”：一味附和不是义气，能在该说时把实话递过去，才是。当然，说之前先确定自己是真为对方着想，不是挑刺。
- 现有情境（scene，供参考风格，可改可不改）：夸朋友时，心里清楚他强是真强、但某个地方又总觉得差点意思的时候，会想起这句。

### id 494（《论语·子张篇》| 标签：评价、修养、谦逊、判断）
- 原文：曾堂堂乎张也，难与并为仁矣。

- 讲解（insight）：曾子不否认子张的“堂堂”——外在的气象确实出众，但他担心的是另一面：一个人太端着、太注重光鲜形象，反而难与人一起踏踏实实修德进德。修仁是件需要放下身段、坦露真实的事，太“堂堂”的人往往放不下来。对此刻的我，这句是面镜子：形象当然重要，但若把“好看”当成全部，离真实的成长就远了。给别人留个不“完美”的入口，关系才能走深。

### id 495（《论语·子张篇》| 标签：亲情、哀伤、情绪、家庭、真诚、愧疚）
- 原文：曾吾闻诸夫子：『人未有自致者也，必也亲丧乎！』
- 白话：曾子说：“我听老师说过：人没有能把自己的情感尽情抒发到极致的时候，如果有，一定是在父母去世的时候吧。”
- 讲解（insight）：曾子转述的话点出一个真相：人平时几乎不会把感情放到极致，总是收着、端着、替别人考虑着；唯有至亲离世那一刻，人才能毫无保留地哭出来。这不是软弱，是感情终于找到了可以完全放开的地方。对此刻的我，这句话是提醒：别等“亲丧”才允许自己真情流露。平时对在意的人，别把该说、该表达的都攒着——攒着攒着，就只剩下丧亲时那一次爆发。

### id 496（《论语·子张篇》| 标签：家庭、孝顺、传承、坚持、尊重）
- 原文：曾吾闻诸夫子：『孟庄子之孝也，其他可能也，其不改父之臣，与父之政，是难能也。』
- 白话：曾子说：“我听老师说：孟庄子的孝，其他方面别人也许能学着做到，唯独他不更换父亲留下来的臣子、不改动父亲定下的政事，这一点是别人难以做到的。”
- 讲解（insight）：孟庄子的孝特别在他接手后“不改”：父亲用的人、定的规矩，他先保持原样，没有一上来就推倒重来。这不是没主见，而是对前人成果的尊重和稳定过渡的智慧——先弄懂为什么这么安排，再谈调整。对此刻的我，无论是接班、接项目还是接手任何“前人遗产”，这句都提醒：先学会“不改”，别急着证明自己而全盘推翻。看懂旧的，你才有资格谈新的。
- 现有情境（scene，供参考风格，可改可不改）：接手长辈或前任留下的一摊子事，忍不住想“全换成我的”的时候，会想起这句。
- 现有今日行动（practice，供参考风格）：今天对一件“旧规矩”先按原样跑一天，只观察，不动它。

### id 497（《论语·子张篇》| 标签：职场、同理心、仁爱、责任、治理）
- 原文：孟氏使阳肤为士师，问于曾子。曾上失其道，民散久矣！如得其情，则哀矜而勿喜。
- 白话：孟氏让阳肤去做掌刑狱的士师，阳肤去请教曾子。曾子说：在上位的人早就背离了正道，民心离散很久了。你如果查明了案情的实情，要哀怜同情他们，而不要沾沾自喜。
- 讲解（insight）：曾子嘱咐刚上任管刑狱的阳肤：查明了案情，别高兴。他说民心离散久了，人走到犯错这一步，往往有无奈处、有不得已。抓到别人出错、证明自己判断正确，确实有种本能快感，可这种“喜”恰恰危险。成熟的人看到他人犯错，先想他经历了什么，而不是为自己的正确喝彩。无论管下属、判对错还是看人翻车，先哀矜、再判断，才能照见事情全貌。
- 现有情境（scene，供参考风格，可改可不改）：作为负责人或处理他人过失的人，证据确凿地认定对方确实有错，却高兴不起来的时候。
- 现有今日行动（practice，供参考风格）：今天想下结论之前，先在心里替他把来路走一遍，再开口。

### id 500（《论语·子张篇》| 标签：学习、谦虚、无师、传承、成长）
- 原文：衞公孙朝问于子贡曰：「仲尼焉学？子贡曰：「文、武之道，未坠于地，在人。贤者识其大者，不贤者识其小者，莫不有文、武之道焉。夫子焉不学？而亦何常师之有？
- 白话：卫国的公孙朝问子贡：仲尼的学问是从哪学来的？子贡说：文王、武王的道并没有失传，还散落在人世间。贤能的人记住它的大处，不贤的人记住它的小处，哪里都有文武之道。夫子哪里不学？又哪里有固定的老师呢？
- 讲解（insight）：别人以为孔子有隐秘的师承，子贡说得很朴素：道没失传，就在人间，贤者取它的大处，普通人取它的小处，处处都有。孔子不是不学，而是什么都学，只是没有固定老师。现代人容易把成长误解成找到一位大师、一套课程、一条捷径。真正的学习恰恰相反：向高手学大处，向普通人学小处。没有固定老师，意味着没有人能替你完成处处留心这件事。
