- 现有情境（scene，供参考风格，可改可不改）：你越想把控全局、事事插手，团队反而越乱越慢的时候。
- 现有今日行动（practice，供参考风格）：今天把一件你习惯亲手做的活完整交出去，只盯结果不插手。

### id 391（《论语·卫灵公篇》| 标签：诚信、言行、职场、品格、人际）
- 原文：子张问行。言忠信，行笃敬，虽蛮貊之邦行矣。言不忠信，行不笃敬，虽州里行乎哉？立，则见其参于前也；在舆，则见其倚于衡也。夫然后行。子张书诸绅。
- 白话：子张问怎样能处处行得通。孔子说：“说话忠诚守信，做事笃实恭敬，就算到野蛮边远的地方也走得通。说话不忠不信，做事不笃实恭敬，就算在本乡本土能行得通吗？站着，仿佛就看见这几个字立在眼前；坐车，仿佛看见它们刻在车辕上。这样才能处处通达。”子张把这些话写在腰带上。
- 讲解（insight）：子张问的是通行证，孔子的答案很朴素：说话算话、做事认真，这套到哪都吃香，不需要看人下菜。所谓“行”的关键，不是会来事，而是让人信得过。对此刻的我，与其研究怎么在新环境里“混得开”，不如先把“靠得住”三个字做到位：答应的事有回音，接的活有交代。信任是最便宜的通行证，但只发给长期靠谱的人。
- 现有情境（scene，供参考风格，可改可不改）：换了个新环境、新团队，担心“我这一套行不行得通”的时候。
- 现有今日行动（practice，供参考风格）：今天把手头一件快做完的事彻底收尾，别留尾巴。

### id 392（《论语·卫灵公篇》| 标签：正直、原则、环境、进退、适应）

- 讲解（insight）：孔子同时欣赏两种人：史鱼不论环境多坏都一根筋地直，蘧伯玉则看环境说话、能收能放。两种都值得敬，但你要清楚自己是哪一种，也要看环境值不值得硬碰。对此刻的我，最大的误区是“一套姿势走到底”：要么永远当愣头青，要么永远缩着。成熟的判断是，原则不变，但表达的方式、进退的时机可以调。硬刚和收着都只是工具，别让工具定义你。

- 白话：孔子说：“可以和他谈却不谈，就会错过这个人；不可以和他谈却谈了，就会说错话。有智慧的人既不错过人，也不说错话。”
- 讲解（insight）：孔子把说话的门道总结成两条失误：该说的时候没说，错过人；不该说的时候说了，说漏嘴。聪明人是两头都不误。对此刻的我，开口前先做个判断：对方接得住吗？此刻合适吗？场合安全吗？这不是教人虚伪，而是对自己说的话负责——真正值得深谈的话，要给值得的人留到合适的时机。沉默不是冷漠，是不让真心话掉进错的地方。
