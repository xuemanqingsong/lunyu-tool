- 白话：发愤用功时忘了吃饭，快乐得忘了忧愁，连衰老将要到来都不觉得。
- 讲解（insight）：孔子晚年的自我描述，关键词是「忘」：忘食、忘忧、忘老。专注是最好的抗焦虑药——不是压住念头，而是让念头没有空当。反过来说，饭不香、乐不来、总觉得自己在老去，往往不是身体先出问题，是生活里缺少值得「发愤」的事。重建的顺序：先找一件能让你忘记吃饭的小事，忧愁和年龄感会在投入中自然退场。
- 现有情境（scene，供参考风格，可改可不改）：做什么都提不起劲、情绪持续低落的时候
- 现有今日行动（practice，供参考风格）：今天给自己留两小时，深度做一件真心喜欢的事，别被打断。

### id 167（《论语·述而篇》| 标签：学习、努力、谦虚、求知、成长）
- 原文：我非生而知之者，好古，敏以求之者也。
- 白话：孔子说：“我不是生来就什么都知道的人，而是爱好古代文化、靠勤勉敏捷去求得知识的人。”
- 讲解（insight）：孔子亲口说“我非生而知之”——连他都承认知识是学来的，不是天生的。这句话最治愈的地方在于：它把“聪明”重新定义成“好古、敏以求之”，即肯钻研、肯下功夫。天赋决定起点，求知的劲头决定你走多远。对此刻的我：别再拿“我没那个天赋”当退路，别人会的，多半也是啃出来的；把想做的事当成可以学的技能，今天学一点，就比昨天强一点。
- 现有情境（scene，供参考风格，可改可不改）：看别人聪明、起步早，觉得自己天赋不如人、追不上而泄气的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天去上那件'自认没天赋'的事的第一课，就二十分钟。

### id 168（《论语·述而篇》| 标签：原则、理性、边界、判断、价值观）
- 原文：子不语：怪、力、乱、神。
- 白话：（弟子们记下）孔子不谈论怪异的事情、勇力、叛乱和玄异之说。
- 讲解（insight）：孔子不谈“怪力乱神”，不是胆小或否认，是觉得这些既不靠谱又不解决实际问题，谈它纯属消耗。这条很超前：两千多年前就有人主张把注意力放在“能验证、能处理”的事情上。今天的奇闻、传言、焦虑贩卖，本质都是“怪力乱神”的变体，刷得越多越空虚。对此刻的我：遇到无法证实、又引着情绪走的信息，先放下；把力气省下来处理眼前能改的实事。
- 现有情境（scene，供参考风格，可改可不改）：群里刷屏的阴谋论、怪力乱神的传闻，让你将信将疑、又忍不住点进去的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天遇到真假不明的爆料忍住不转，省下的时间拿去办一件拖着的实事。

### id 169（《论语·述而篇》| 标签：学习、谦虚、榜样、成长、自省）
- 原文：三人行，必有我师焉。择其善者而从之，其不善者而改之。
- 白话：几个人同行，其中必定有值得我学习的人：选他们的优点去学习，看到缺点就反省自己有没有同样的毛病。
- 讲解（insight）：觉得周围没一个值得学的人时，问题多半不在周围。孔子的高明在于双向操作：见贤，取其善；见不贤，也不浪费——把它当镜子照自己。这样，所有人都是你的老师，你等于站在一个全免费的、永不打烊的商学院里。职场里那些你看不惯的人，恰恰是最好的反面教材：他让你清楚看到某种行为模式的代价。
- 现有情境（scene，供参考风格，可改可不改）：看不上身边人、觉得谁都不行的时候
- 现有今日行动（practice，供参考风格）：今天从接触过的人里挑一个，写下他身上一样值得你学的地方。

### id 170（《论语·述而篇》| 标签：自信、信念、勇气、逆境、原则）
- 原文：天生德于予，桓魋其如予何！
- 白话：孔子说：“上天把德性赋予了我，桓魋又能把我怎么样呢！”
- 讲解（insight）：桓魋要杀孔子，孔子撂下这句硬话。这不是狂妄，是“我心里有数”的底气：我知道自己是谁、在做什么，外界的威胁犹豫不了我。人最难的时候，靠的就是这股“我的价值不由你说了算”的定力。对此刻的我：被人否定、被人踩的时候，先分清楚——那是我的问题，还是对方的恶意；只要行得正，就别被一句“你不行”打趴下，你的分量自己最清楚。
- 现有情境（scene，供参考风格，可改可不改）：被针对、被排挤，但心里清楚自己没做错、不愿低头的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天若被贬低，写下你最近做成的三件事，替自己作证。

### id 171（《论语·述而篇》| 标签：坦诚、诚信、开放、教育、正直）
- 原文：二三子，以我为隐乎？吾无隐乎尔！吾无行而不与二三子者，是丘也。
- 白话：孔子说：“你们这些学生，以为我对你们有所隐瞒吗？我对你们没有隐瞒！我没有什么言行是不让你们看到的，这就是我孔丘的为人。”
- 讲解（insight）：学生猜老师是不是留了一手，孔子直接摊开：“吾无行而不与二三子者”——我做的每一件事都摊在你们眼前。这份坦荡很珍贵：教人的人不怕被学走，学习者也不必总琢磨对方留了啥。真正厉害的人，底牌敢亮给你看，因为你看得懂、做得到，也得下同样的功夫。对此刻的我：向人求教时少一点疑心，多把对方平时怎么做的一一学来；坦荡请教，对方才肯教。
- 现有情境（scene，供参考风格，可改可不改）：想学点真本事、又怕对方藏着掖着不肯全教的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天挑一件佩服的人手上的事，从第一步看到收尾，别只问结果。

### id 172（《论语·述而篇》| 标签：教育、学习、诚信、行动、价值观）
- 原文：子以四教：文、行、忠、信。
- 白话：（弟子们记下）孔子用四个方面教育学生：文献知识、实际行动、忠诚、诚信。
- 讲解（insight）：孔子教人不只教“文”（知识），还教“行”（去做）、“忠”（认真）、“信”（可靠）。这份课程表放到今天依然完整：光有知识没人信你，光会来事没真功夫也走不远。很多人把学习窄化成“知道”，其实知道和做到之间，隔着“行忠信”三道坎。对此刻的我：衡量学习成果，别问“记住了吗”，问“能做吗、靠得住吗”；被人信任，是最好的毕业证。
- 现有情境（scene，供参考风格，可改可不改）：学了一堆理论，却发现事到临头不会用、别人也信不过你的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天把学到的一招真用一遍，再兑现一个答应过的小承诺。

### id 173（《论语·述而篇》| 标签：坚持、真诚、谦虚、自我认知、成长）
- 原文：圣人，吾不得而见之矣！得见君子者，斯可矣。善人，吾不得而见之矣！得见有恒者，斯可矣。亡而为有，虚而为盈，约而为泰，难乎有恒矣！
- 白话：孔子说：“圣人，我见不到了，能见到君子，也就够了。”又说：“善人，我见不到了，能见到有恒心的人，也就够了。没有却装作有，空虚却装作充实，穷困却装作阔绰，这样的人很难有恒心了！”
- 讲解（insight）：孔子把标准放得很低也很高：圣人和善人太难碰到，可“有恒者”——能一直坚持做点什么的人——就已经很可贵了。他还点了装样子的毛病：没有装有钱、空心装充实的人，很难有恒，因为里子不实，撑不住。对此刻的我：别总盯着“成为厉害的人”，先做一个“有恒的人”，把一件小事稳稳坚持住，就超过大半数人；也别装，装出来的坚持，装不了几天。
- 现有情境（scene，供参考风格，可改可不改）：觉得自己离“优秀”“厉害”差得远，连坚持一件小事都做不到而沮丧的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天挑一件十分钟的小事稳稳做完，先做到'有恒'这一天。

### id 174（《论语·述而篇》| 标签：仁慈、克制、生态、习惯、尊重）
- 原文：子钓而不纲，弋而不射宿。
- 白话：（弟子们记下）孔子钓鱼只用鱼竿，不用大网去捞；射鸟时，不射那些归巢栖息的鸟。

### id 175（《论语·述而篇》| 标签：学习、方法、谨慎、求真、判断）
- 原文：盖有不知而作之者，我无是也。多闻，择其善者而从之，多见而识之，知之次也。
- 白话：孔子说：“大概有那种自己不懂却凭空造作的人，我没有这种毛病。多听，选择其中好的去跟从；多看，把好的记在心里，这是次一等的求知方式了。”
- 讲解（insight）：孔子最怕“不知而作”——不懂装懂、凭空造作，所以他宁可“多闻择善、多见而识”，先大量吸收再判断。这句话对今天太对症：网上人人都能评论，但没调查就没发言权。先学后说，不丢人；不懂乱说，才砸招牌。对此刻的我：表达之前，先攒够听和看的分量；遇到不懂的领域，别硬撑场子，把“我了解不多”说出口，比装懂体面得多。
- 现有情境（scene，供参考风格，可改可不改）：想发表看法，但底子薄、心里虚，不知道该不该开口的时候，你会想起这句。
- 现有今日行动（practice，供参考风格）：今天对想发言的话题先看三个来源，再决定开不开口。
