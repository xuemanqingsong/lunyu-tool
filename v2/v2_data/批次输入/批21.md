### id 503（《论语·子张篇》| 标签：评价、谦逊、智慧、表达、尊重）
- 原文：陈子禽谓子贡曰：「子为恭也，仲尼岂贤于子乎？子贡曰：「君子一言以为知，一言以为不知，言不可不愼也！夫子之不可及也，犹天之不可阶而升也。夫子之得邦家者，所谓『立之斯立，道之斯行，绥之斯来，动之斯和。其生也荣，其死也哀』。如之何其可及也？
- 白话：陈子禽对子贡说：你是故作恭敬吧，孔子难道真比你贤？子贡说：君子一句话可以显得有智慧，一句话也可以显得没智慧，说话不可不谨慎。夫子的不可企及，就像天不能搭梯子爬上去一样。夫子如果得到治理国家的机会，就能做到：要让百姓立身他们就立身，要引导他们就前行，要安抚他们就归附，要发动他们就齐心。他活着让人感到荣耀，去世让人感到哀痛。这怎么能赶得上呢？
- 讲解（insight）：陈子禽以为子贡是客气，子贡却认真起来：一句话见智见愚，话不能乱说。他没有空口吹捧，而是给出“不可及”的具体理由——那种带动人的能力，让人愿意跟着走，活着荣耀、死了哀痛。现代人评价师长、前辈，容易走两个极端：要么不服气，要么盲目捧。子贡示范的是第三种：用具体的判断去辨认一个人真正的分量，而不是被别人的问话牵着走。
- 现有情境（scene，供参考风格，可改可不改）：有人质疑你敬重的师长“不过如此”，让你觉得不回应一下说不过去的时候。
- 现有今日行动（practice，供参考风格）：今天开口评价人前停三秒：这句显的是判断力，还是轻率？

### id 504（《论语·尧曰篇》| 标签：领导、责任、治理、公正、民生、宽容、规划）
- 原文：尧曰：「咨！尔舜！天之历数在尔躬，允执其中！四海困穷，天禄永终。舜亦以命禹。曰：「予小子履，敢用玄牡，敢昭吿于皇皇后帝：有罪不敢赦。帝臣不蔽，简在帝心！朕躬有罪，无以万方；万方有罪，罪在朕躬。「周有大赉，善人是富。「虽有周亲，不如仁人；百姓有过，在予一人。谨权量，审法度，修废官，四方之政行焉。兴灭国，继绝世，擧逸民，天下之民归心焉。所重：民、食、丧、祭。宽则得众，信则民任焉，敏则有功，公则说。
- 白话：尧说：唉！舜啊！上天的使命落在你身上，要真诚地把握中道！如果天下百姓陷入困苦，你的天禄也就终结了。舜也用这番话告诫禹。商汤说：我小子履，冒昧地献上黑色公牛，明白地禀告伟大的天帝：有罪的人我不敢擅自赦免，臣下的善恶我也不敢隐瞒，这些都明察在您心里！如果我有罪，不要牵连天下百姓；如果天下百姓有罪，罪都在我一个人身上。周朝大赏天下，善人都得到封赏。即使有至亲，也不如仁德之人；百姓有过错，责任在我一人。谨慎统一度量衡，审定法令制度，修复废弃的官职，天下的政事就能推行。复兴被灭亡的国家，接续断绝的世族，举用隐逸的贤人，天下的民心就归附了。所重视的是：百姓、粮食、丧礼、礼制。宽厚就能得到众人拥护，诚信就能让百姓信任，勤勉就有功绩，公平就让人心悦诚服。
- 讲解（insight）：这篇是古代帝王交接时的嘱托，反复叮嘱同一件事：权力越大，越要把过错往自己身上揽，把好处往别人身上推。“百姓有过，罪在朕躬”，出了事先问责自己，是这里最重的话。现代人当组长、带项目、管小团队，出岔子时本能是甩锅。敢说一句“这责任我来”，反而最能赢得人心。收尾的“宽则得众，信则民任，敏则有功，公则说”，就是明白的管理学。

- 现有今日行动（practice，供参考风格）：今天再有闪失，开口先揽下“责任在我”，然后一起想怎么改。

### id 505（《论语·尧曰篇》| 标签：领导、治理、原则、德行、管理）
- 原文：子张问于孔何如斯可以从政矣？尊五美，屛四恶，斯可以从政矣。子张曰：「何谓五美？君子惠而不费，劳而不怨，欲而不贪，泰而不骄，威而不猛。子张曰：「何谓惠而不费？因民之所利而利之，斯不亦惠而不费乎！择可劳而劳之，又谁怨？欲仁而得仁，又焉贪？君子无众寡，无小大，无敢慢，斯不亦泰而不骄乎？君子正其衣冠，尊其瞻视，俨然人望而畏之，斯不亦威而不猛乎！子张曰：「何谓四恶？不教而杀谓之虐；不戒视成谓之暴；慢令致期谓之贼；犹之与人也，出纳之吝，谓之贪。
- 白话：子张问孔子：怎样才可以治理政事？孔子说：尊崇五种美德，摒弃四种恶政，就可以从政了。子张问：什么是五美？孔子说：君子给人好处而不耗费自己，役使百姓而不招致怨恨，有追求而不贪婪，安泰而不骄傲，威严而不凶猛。子张问：什么叫给人好处而不耗费？孔子说：顺着百姓的利益点去帮助他们，不就是给人好处而不耗费吗？选择百姓能胜任的事让他们去做，谁会怨恨呢？追求仁德而得到了仁德，还贪什么？君子不管人多人少、事大事小，都不敢怠慢，不就是安泰而不骄傲吗？君子端正衣冠，庄重地看待事物，严肃得让人望而生敬，不就是威严而不凶猛吗？子张问：什么是四恶？孔子说：不先教导就杀戮，叫虐；不先告诫就苛求成果，叫暴；命令下达得缓慢却限期紧迫，叫贼；同样是给人东西，出手时却吝啬，叫贪。
- 讲解（insight）：子张问怎么做管理者，孔子给出一份五美四恶的清单。五美是方向：惠而不费，顺着人的实际需要帮人；劳而不怨，派活派到人乐意干；泰而不骄，威而不猛，有气场但不吓人。四恶里最扎心的两条：不教而杀谓之虐——从没教过，一出错就重罚；慢令致期谓之贼——布置时不说明白，到点又催命。带团队、教孩子都能对号入座：先教再要求，先说清再计时。
- 现有情境（scene，供参考风格，可改可不改）：刚当上小领导，一边怕管不住人，一边又怕自己对别人太凶的时候。
- 现有今日行动（practice，供参考风格）：今天布置任务，先把怎么算做好、什么时候要，一并说清，别让人猜。

### id 506（《论语·尧曰篇》| 标签：敬畏、礼仪、识人、智慧、原则）
- 原文：不知命，无以为君子也；不知礼，无以立也；不知言，无以知人也。
- 白话：孔子说：不懂天命，就无法成为君子；不懂礼，就无法立身处世；不懂辨别言语，就无法了解人。
- 讲解（insight）：这是整部《论语》的收尾句，用三句话总结一生：知命、知礼、知言。知命不是认命，而是分得清哪些事自己能改、哪些改不了，对改不了的保持坦然；知礼不是死守规矩，而是懂得与人相处的边界和分寸；知言是能听懂话背后的意思，才看得清人。现代人常在这三处栽跟头。把力气用在能改的事上，把分寸用在相处里，放到哪一年都用得上。
- 现有情境（scene，供参考风格，可改可不改）：一路顺风顺水，直到遇见一件拼尽全力也改变不了的事，第一次想“有些东西是不是我控制不了”的时候。
- 现有今日行动（practice，供参考风格）：今天只做第一栏里的事；第二栏那件，写下来，允许它先搁着。
