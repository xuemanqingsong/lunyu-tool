- 现有情境（scene，供参考风格，可改可不改）：当你看到有人越界、把规则当摆设，而身边人都说“算了别管”的时候。
- 现有今日行动（practice，供参考风格）：今天写下一条你不再让步的底线，并想好下次开口的第一句话。

### id 42（《论语·八佾篇》| 标签：原则、边界、诚信、领导、摆烂）
- 原文：三家者，以雍彻。『相维辟公，天子穆穆。』奚取于三家之堂？
- 白话：孟孙、叔孙、季孙三家行完宗庙之礼，撤供品时唱《雍》诗。孔子说：《雍》诗里唱“诸侯助礼，天子庄严肃穆”，这歌词用在三家的厅堂上，图什么呢？
- 讲解（insight）：三家用天子规格之曲，是名不副实的包装。孔子问“奚取于三家之堂”——这规格安在你们头上，你们自己也知道不合适吧。现实中也有这种错位：没有那个分量的人硬撑那个场面，越用力越露怯，花了大钱还落个笑话。对此刻的我有什么用：做事之前先对一下“我的位置和我要的规格匹不匹配”，能替你省掉很多钱，也省掉很多尴尬。
- 现有情境（scene，供参考风格，可改可不改）：当你发现有人盗用不属于他的名分和排场，还要装得很得体的时候。
- 现有今日行动（practice，供参考风格）：今天取消一项纯为脸面的开销，把这笔钱挪到一件实事上。

### id 43（《论语·八佾篇》| 标签：本质、原则、意义、价值观、空虚）
- 原文：人而不仁，如礼何？人而不仁，如乐何？
- 白话：孔子说：一个人没有仁心，礼对他有什么用？音乐对他有什么用？
- 讲解（insight）：孔子不是反对礼乐，是说礼乐的前提是仁心。没有仁心，礼就是空壳，乐就是背景音，排场越大越显得空洞。今天很多“仪式感”做得很足，却让人尴尬，就是因为只有形式没有温度。反过来，心里真有那份在意，哪怕形式简陋，也照样动人。对此刻的我有什么用：与其忙着补形式，不如先问自己，那件事里到底有没有真心。
- 现有情境（scene，供参考风格，可改可不改）：当你参加一场走形式的会议或婚礼，全程只有流程、没有人心的时候。
- 现有今日行动（practice，供参考风格）：今天挑一件徒有其表的事，往里面加一点你自己的诚意。

### id 44（《论语·八佾篇》| 标签：节俭、态度、本质、仪式、心态、空虚、无效社交）
- 原文：林放问礼之本。大哉问！礼，与其奢也，宁俭；丧，与其易也，宁戚。
- 白话：林放问礼的根本是什么。孔子说：这个问题问得好！礼，与其铺张奢侈，宁可节俭；丧事，与其办得周全妥帖，宁可心中哀戚。
- 讲解（insight）：孔子直接给了一条取舍标准：形式可以俭省，感情不能缺席。丧事流程做得滴水不漏，心里却没有悲伤，那等于什么都没办。今天消费主义给很多仪式标了价，好像花钱越多越有诚意。孔子提醒，本末要分清：形式是末，心意是本。对此刻的我有什么用：下次操办任何“仪式”，先确认心意到位没有，再谈排场，顺序别搞反。
- 现有情境（scene，供参考风格，可改可不改）：当你为一场丧事、婚礼或家宴纠结要不要大操大办，怕“不够体面”的时候。
- 现有今日行动（practice，供参考风格）：今天把要办的那场仪式砍掉一项花销，换成一件走心的小事。

### id 45（《论语·八佾篇》| 标签：文化、归属、价值观、自信、冲突、冲动、忍耐）
- 原文：夷狄之有君，不如诸夏之亡也。
- 白话：孔子说：边远部族即使有君主，也比不上中原各国虽然有君不君、礼崩乐坏，却没有像样的君主。
- 讲解（insight）：这句话带着当时的天下观，不必硬套今天的民族话题。孔子想说的是：一个地方哪怕暂时没有好领袖，只要文化根基、礼节人心还在，就还有救；反过来，只有权力没有文化，再严整也立不住。今天看一个公司、一个社区也一样：它靠制度压着，还是靠共识撑着，差别很大。对此刻的我有什么用：判断环境值不值得待，先看它的文化底子，别只看表面管理。
- 现有情境（scene，供参考风格，可改可不改）：当你身处一个表面有秩序、实则人心涣散的环境，怀念那种“乱但有文化底蕴”的地方的时候。
- 现有今日行动（practice，供参考风格）：今天为所在的环境做一件提升共识的小事，比如分享一次你的经验。

### id 46（《论语·八佾篇》| 标签：原则、边界、管理、判断、低谷、纠结、困境）
- 原文：季氏旅于泰山。子谓冉有曰：「女弗能救与？对曰：「不能。呜呼！曾谓泰山不如林放乎？
- 白话：季氏要去泰山行礼。孔子对冉有说：你不能劝阻他吗？冉有说：不能。孔子说：唉！难道泰山之神还不如林放懂礼吗？
- 讲解（insight）：孔子这句其实是在戳冉有：你明明知道季氏拜泰山不合礼，却连试都不试就答“不能”。连泰山都懂得不接受越礼的供奉，你一个读书人倒先泄了气。现实里我们常做冉有：预判“劝了也没用”，于是从不开口。可很多时候，对方等的恰恰是有人认真说一句。对此刻的我有什么用：别替别人先放弃，该说的话，说出口才算数。
- 现有情境（scene，供参考风格，可改可不改）：当你明知朋友或同事要做一件越格的事，却觉得“反正劝不动”，干脆闭嘴的时候。
- 现有今日行动（practice，供参考风格）：今天把那句'为你好'的话说出口，只讲事理，不掺情绪。

### id 47（《论语·八佾篇》| 标签：竞争、心态、礼仪、谦让、人际、内耗）
- 原文：君子无所争，必也射乎！揖让而升，下而飮，其争也君子。
- 白话：孔子说：君子没有什么可争的，如果说有，那就是射箭吧。但也要先作揖礼让再上场，射完下来一起喝酒，这样的竞争也是君子的竞争。
- 讲解（insight）：孔子不是说不竞争，是说竞争要有程序感：上场前礼让，结束后还能一起喝酒。输赢放在中间，人和人的体面放在两头。今天很多内耗就来自把竞争变成零和厮杀——赢了结仇，输了积怨。其实一次良性的竞争，反而是互相看清水平的窗口。对此刻的我有什么用：把“打败对方”改成“赛出水平”，结果反而更干净，人也留得下。
- 现有情境（scene，供参考风格，可改可不改）：当你和同事竞聘同一个岗位、和朋友竞争同一个机会，不知道该怎么“争”的时候。
- 现有今日行动（practice，供参考风格）：今天跟那位同你竞争的人打个招呼，赛后一起喝杯东西。

### id 48（《论语·八佾篇》| 标签：学习、思考、领悟、成长、沟通）
- 原文：子夏问曰：「『巧笑倩兮，美目盼兮，素以为绚兮。』何谓也？绘事后素。曰：「礼后乎？起予者商也，始可与言《诗》已矣。
- 白话：子夏问：《诗经》里“巧笑倩兮，美目盼兮，素以为绚兮”是什么意思？孔子说：先有洁白的底子，然后才在上面绘画。子夏说：那么礼也是在仁德之后吗？孔子说：启发我的人是你啊，这才可以和你谈《诗》了。
- 讲解（insight）：孔子教《诗》不急着给标准答案，而是等子夏自己从“绘画要画在白底上”联想到“礼要有仁做底子”。这是真正的教法：给个启发，让学生自己跨出那一步。子夏问出“礼后乎”，孔子高兴得说“起予者商也”。对此刻的我有什么用：学习时别只记结论，试着从例子往后多想一步，那一步才是真正长在你身上的。
- 现有情境（scene，供参考风格，可改可不改）：当你学会一个新东西，突然想通它背后的道理，整个人豁然开朗的时候。
- 现有今日行动（practice，供参考风格）：今天学任何东西时，多追一层'它背后为什么成立'，并讲给一个人听。

### id 49（《论语·八佾篇》| 标签：学习、知识、判断、方法）
- 原文：夏礼，吾能言之，杞不足征也；殷礼，吾能言之，宋不足征也。文献不足故也，足，则吾能征之矣。
- 白话：孔子说：夏朝的礼，我能说出来，但杞国不足以作证；殷朝的礼，我能说出来，但宋国不足以作证。因为文献和贤人都不够，如果够，我就能证实它们了。
- 讲解（insight）：孔子讲历史最难得的是这份诚实：我能说出我的看法，但证据不足，我承认证据不足。他没有因为“我能言”就假装“我知道”，而是把“知道”和“证实”严格分开。今天的信息环境里，最不缺的就是敢下结论的人，缺的是敢说“这个我还没证实”的人。对此刻的我有什么用：给结论标上置信度，没查证的就明说没查证，你的话会因此更可信。
- 现有情境（scene，供参考风格，可改可不改）：当你写东西或做判断，手里只有二手资料，想下结论又不敢笃定的时候。
- 现有今日行动（practice，供参考风格）：今天引用任何信息前，先点开一次原始出处；查不到，就标上'待核实'。

### id 50（《论语·八佾篇》| 标签：态度、仪式、原则、虔诚、失业）
- 原文：禘自既灌而往者，吾不欲观之矣。
