- 白话：孔子说：谁说微生高正直？有人向他借醋，他家里没有，却去邻居家借来给别人。
- 讲解（insight）：微生高被传为直人，孔子一句话戳破：有人借醋，他没有，居然去邻家借了再给。这算什么直？直不是有求必应，而是如实告知——我没有。为了维持“好人”人设而绕弯子，恰恰是不直。今天太多人活在“答应之后偷偷补救”里，把自己累死，把关系搞复杂。对此刻的我有什么用：做不到就直说，比绕弯子帮忙更省事，也更真诚。
- 现有情境（scene，供参考风格，可改可不改）：当你为了显得自己“乐于助人”，答应一件自己根本做不到的事，再偷偷找补的时候。
- 现有今日行动（practice，供参考风格）：今天再遇到办不到的请求，如实一句'我办不了'，不绕弯子。

### id 117（《论语·公冶长篇》| 标签：虚伪、正直、人际、信任、面子、讨好）
- 原文：巧言、令色、足恭，左丘明耻之，丘亦耻之。匿怨而友其人，左丘明耻之，丘亦耻之。
- 白话：孔子说：花言巧语、装出好脸色、过分恭敬，左丘明以此为耻，我也以此为耻。心里藏着怨恨却还和那人交朋友，左丘明以此为耻，我也以此为耻。
- 讲解（insight）：孔子连着点名两种他最看不上的人：一种靠巧言令色讨好，一种藏着怨气还维持表面的友好。后一种尤其消耗——嘴上和平，心里记账，早晚翻船。人际关系里最贵的不是圆滑，而是“表里一致”带来的信任。对此刻的我有什么用：与其假笑维持，不如礼貌地拉开距离；讨厌一个人不可耻，装喜欢才可耻。
- 现有情境（scene，供参考风格，可改可不改）：当你明明讨厌一个人，却对着他笑脸相迎，转身又和朋友吐槽他的时候。
- 现有今日行动（practice，供参考风格）：今天对他把热情降成礼貌：不表演喜欢，也不再背后补刀。

### id 118（《论语·公冶长篇》| 标签：理想、朋友、分享、奉献、意义、价值观、陪伴）
- 原文：颜渊、季路侍。盍各言尔志？子路曰：「愿车马衣裘，与朋友共，敝之而无憾。颜渊曰：「愿无伐善，无施劳。子路曰：「愿闻子之志。老者安之，朋友信之，少者怀之。
- 白话：颜渊、子路陪侍。孔子说：何不各说说你们的志向？子路说：愿意把车马衣服与朋友共用，用坏了也不遗憾。颜渊说：愿意不夸耀自己的好处，不表白自己的功劳。子路说：想听先生的志向。孔子说：让老年人得到安养，让朋友得到信任，让年轻人得到关怀。
- 讲解（insight）：三个人的志向一对比，层次很清楚：子路讲分享财物，颜渊讲修养自己，孔子讲让身边的人各得其所——老有所安、朋友互信、少有所怀。孔子的志向没有一个字提到自己，全落在具体的人身上。今天聊理想，我们常只谈个人成就，很少想到“我能让哪几个人过得更好”。对此刻的我有什么用：理想不必宏大，先想清“我想让谁安、让谁信、让谁怀”。
- 现有情境（scene，供参考风格，可改可不改）：当朋友聊到人生理想，大家都在说“搞钱、出名”，你心里却冒出别的答案的时候。
- 现有今日行动（practice，供参考风格）：今天从里面挑一个人，为他做一件他真正受用的小事。

### id 119（《论语·公冶长篇》| 标签：自省、认错、内疚、反思、诚实、自责）
- 原文：已矣乎！吾未见能见其过，而内自讼者也。
- 白话：我没见过能发现自己的过错、并在内心认真审判自己的人。
- 讲解（insight）：孔子叹的是「内自讼」的稀缺：多数人对自己错事的处理流程是——躲（不看见）、推（怪环境）、忘（时间冲淡）。真正的「讼」是开庭审自己：我当时的动机是什么？动机里哪个成分是贪、怕、懒？下次同样的触发出现时怎么办？这一套走完，错误才变成资产。但注意，孔子也暗示了它的难度——能做到的人凤毛麟角，所以哪怕只审一件，你就已经在人群的前排。
- 现有情境（scene，供参考风格，可改可不改）：道理都懂、就是改不了的时候
- 现有今日行动（practice，供参考风格）：今天挑最近一个小错，写三行：发生了什么、我图什么、下次怎么办。

- 原文：十室之邑，必有忠信如丘者焉，不如丘之好学也。

### id 121（《论语·雍也篇》| 标签：领导、管理、简单、效率、原则）
- 原文：雍也，可使南面。仲弓问子桑伯子。可也，简。仲弓曰：「居敬而行简，以临其民，不亦可乎？居简而行简，无乃大简乎？雍之言然。
- 白话：孔子说：冉雍可以让他面向南面坐，治理一方。仲弓问子桑伯子这人如何。孔子说：可以，他办事简约。仲弓说：内心恭敬而办事简约，这样治理百姓不也很好吗？如果内心也简单随便，办事也简单，那就太简单了吧？孔子说：你说得对。
- 讲解（insight）：仲弓这句话说出了“简约”的正确用法：心里敬着这件事，手里只抓重点，这叫“居敬行简”；如果心里也松散，手里也随便，那就成了敷衍。很多管理者只学了“简”的外形——少管、放权，却没学“敬”的内核，结果变成甩手。对此刻的我有什么用：简化流程可以，前提是你对这件事本身还存着敬畏，别把放手当成敷衍的借口。
- 现有情境（scene，供参考风格，可改可不改）：当你带团队，纠结该“管得细”还是“放得松”，两头摇摆的时候。
- 现有今日行动（practice，供参考风格）：今天挑一件你在'放'的事，检查结果标准有没有跟着一起掉。

### id 122（《论语·雍也篇》| 标签：学习、情绪、错误、成长、习惯、自律）
- 原文：哀公问：「弟子孰为好学？孔子对曰：「有颜回者，好学；不迁怒，不贰过，不幸短命死矣！今也则亡，未闻好学者也。
- 白话：鲁哀公问：你的学生里谁最好学？孔子说：有个叫颜回的，好学，不把怒气转移到别人身上，不重复犯同样的错误，可惜短命死了！现在没有了，我没听说有谁好学了。
- 讲解（insight）：孔子定义“好学”，不是考试得了多少分，而是两条：不迁怒、不贰过。一个是不拿自己的情绪撒到别人身上，一个是不在同一处摔第二次。这两条都不容易，比背十本书难。今天我们也常把“学习”窄化成刷课、囤知识，却忘了真正的学是改自己。对此刻的我有什么用：今天的学习指标可以只设两条——有没有迁怒，有没有重蹈覆辙。
- 现有情境（scene，供参考风格，可改可不改）：当你被情绪冲昏头迁怒别人，或者同一个坑掉进去第二次，自我厌恶的时候。
- 现有今日行动（practice，供参考风格）：今天动怒时先停三秒再开口；睡前写下一条防'再犯'的规则。

### id 123（《论语·雍也篇》| 标签：金钱、帮助、公平、原则、节俭）
- 原文：子华使于齐，冉子为其母请粟。与之釜。请益，曰：「与之庾。冉子与之粟五秉。赤之适齐也，乘肥马，衣轻裘；吾闻之也：君子周急不继富。原思为之宰，与之粟九百，辞。毋！以与尔邻里乡党乎！
- 白话：公西赤出使齐国，冉有替他母亲请求粮食。孔子说：给他一釜。冉有请求增加，说：给他一庾。冉有却给了五秉。孔子说：公西赤去齐国，乘肥马、穿轻裘，我听说：君子周济急难的人，不接济富有的人。原思当孔子的家臣，孔子给他九百斗粟，他推辞，孔子说：别推辞，拿去向你的邻里乡亲分一点吧。
- 讲解（insight）：“周急不继富”一句话点破了帮人的原则：雪中送炭，别锦上添花。冉有是典型的“好心办错事”——给家境好的公西赤多加粮，而孔子对贫穷的原思反而鼓励他多拿。帮人要看清谁在“急”上、谁在“富”上，否则善心会落空甚至变味。对此刻的我有什么用：出手之前先判断对方是缺还是富，把力气给到最需要的那个缺口。
- 现有情境（scene，供参考风格，可改可不改）：当你好心帮人，却把资源给了并不缺的人，反而冷落了真正需要的人的时候。
- 现有今日行动（practice，供参考风格）：今天把一件准备送出的帮助重新掂量一遍，看它该落到谁头上。

### id 124（《论语·雍也篇》| 标签：出身、潜力、判断、机会、自信）
- 原文：子谓仲弓曰：「犁牛之子，骍且角；虽欲勿用，山川其舍诸？
- 白话：孔子对仲弓说：耕牛生的小牛，毛色纯红、犄角端正，就算人们不想用它做供品，山川会舍弃它吗？
- 讲解（insight）：仲弓出身贫贱，父亲品行也不佳，孔子用“犁牛之子”说：牛虽然是耕牛，但小牛本身毛色角形都符合供品标准，山川不会因为它出身就舍弃它。这是给仲弓撑腰，也是给所有“出身不好”的人打气：评价看的是你本身，不是你爸是谁。对此刻的我有什么用：别把别人对你出身的成见，内化成对自己的判断，你值多少看你自己。
- 现有情境（scene，供参考风格，可改可不改）：当有人因为你的出身、背景或学历看低你，你却知道自己其实行的时候。

### id 125（《论语·雍也篇》| 标签：坚持、信念、价值观、心态、长期）
- 原文：回也，其心三月不违仁。其余，则日月至焉而已矣。
- 白话：孔子说：颜回啊，他的内心能三个月不离开仁德。其他学生，只是偶尔一天、一个月做到而已。
- 讲解（insight）：孔子拿颜回的“三月不违仁”跟别人的“日月至焉”比，说的不是天赋，是持久力。大部分人都是状态型选手：情绪好时做两天，一忙一累就放弃。颜回的厉害在于他不靠状态，把“仁”做成了日常。这给我们的启示很朴素：稳定的品格不是靠爆发，是靠不让它断。对此刻的我有什么用：与其追求完美，不如把一件事做得“天天不断”，哪怕每天只做一点点。
- 现有情境（scene，供参考风格，可改可不改）：当你坚持一个好习惯或好状态几周就崩盘，看到有人却年复一年不松动的时候。
- 现有今日行动（practice，供参考风格）：今天把它的量减到'状态最差也能完成'的地步，只为不断档。
