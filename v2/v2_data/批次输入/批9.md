### id 216（《论语·子罕篇》| 标签：尊重、同理心、礼仪、修养）
- 原文：子见齐衰者，冕衣裳者，与瞽者，见之，虽少必作，过之必趋。
- 白话：孔子见到穿丧服的人、穿礼服的人和盲人，即使对方很年轻，也一定起身；从他们身边经过，一定快步走开。
- 讲解（insight）：这里没有一句大道理，全是身体语言：该起身就起身，该让路就让路。孔子对三种人的尊重——丧服代表悲伤，礼服代表礼制，盲人代表弱势——都是不加迟疑、条件反射式的。尊重不是嘴上客气，而是这些下意识的动作：让开一步、放轻声音、收起玩笑。今天判断一个人修养如何，不用听他怎么说，看他怎么对待卖力气的、落难的、行动不便的人就够了。

### id 217（《论语·子罕篇》| 标签：学习、敬仰、谦虚、成长、方法）

- 白话：颜渊感叹说：越仰望越觉得高，越钻研越觉得深，看着在前面，忽然又到后面去了。老师善于一步步引导：用文化使我广博，用礼使我收敛，我想停都停不下来。我已经用尽了才能，好像有个东西高高地立着，虽然想跟上去，却找不到路径了。

### id 218（《论语·子罕篇》| 标签：诚实、原则、生死、诚信、面子）
- 原文：子疾病，子路使门人为臣。病间，曰：「久矣哉，由之行诈也！无臣而为有臣，吾谁欺？欺天乎？且予与其死于臣之手也，无宁死于二三子之手乎！且予纵不得大葬，予死于道路乎？
