### id 418（《论语·卫灵公篇》| 标签：领导、智慧、仁爱、庄重、方法、完美主义）
- 原文：知及之，仁不能守之，虽得之，必失之。知及之，仁能守之。不庄以莅之，则民不敬。知及之，仁能守之，庄以莅之。动之不以礼，未善也。
- 白话：孔子说：“智慧足以达到，仁德却不能守住，即使得到了，也一定会失去。智慧到了、仁德也守住了，却不能庄重地对待，百姓就不会敬重。智慧到了、仁德守住、也庄重了，行事却不合乎礼，还不算完美。”
- 讲解（insight）：孔子在这里给“做成事”排了四道工序：想明白（知）、守得住（仁）、放得正（庄）、行得妥（礼）。很多人只占第一项——很聪明，拿下了，可守不住，因为缺后面的功课。对此刻的我，可以把任何一次成功拿来检查：我是只赢在了想法上，还是也守得住、做得稳、让人服？缺哪一环，补哪一环。赢一时靠脑子，赢长久靠的是这套完整的功夫。
- 现有情境（scene，供参考风格，可改可不改）：你靠聪明拿下一个成果，却很快守不住、又垮掉的时候。
- 现有今日行动（practice，供参考风格）：今天复盘一件做成的事，找出'得到之后'缺的那道工序，补上一笔。

### id 419（《论语·卫灵公篇》| 标签：识人、用人、能力、格局、判断）
- 原文：君子不可小知，而可大受也。小人不可大受，而可小知也。
- 白话：孔子说：“君子不能从小事上去了解他，却可以让他承担重任；小人不能承担重任，却可能在小事上显得有本事。”
- 讲解（insight）：孔子把人和事分了两档：有人在小事上闪闪发光，但担不起大事；有人平时不显山露水，关键时候靠得住。识别这两类人，比看谁嘴甜更重要。对此刻的我，无论是用人还是选朋友，都别被“小知”迷惑——会说、会表现、会来事，只是轻量级证据；真正的考验在“大受”：压力来了他跑不跑，担子来了他接不接。同时也自问：我是哪一种？
- 现有情境（scene，供参考风格，可改可不改）：你被某人的小聪明迷惑，又担心他扛不了大事的时候。
- 现有今日行动（practice，供参考风格）：今天认领一件没人愿意碰的麻烦事，做到有个交代。

### id 420（《论语·卫灵公篇》| 标签：仁爱、信念、价值、取舍）
- 原文：民之于仁也，甚于水火。水火，吾见蹈而死者矣，未见蹈仁而死者也。
- 白话：孔子说：“百姓对仁的渴求，比水火更迫切。水火，我见过有人踩着它们送命，却从没见过践行仁而送命的。”
- 讲解（insight）：孔子说，人需要仁，像需要水火一样迫切，但没见过谁因为行仁而真出大事的——倒是常常被自己吓退。这说的是两件事：一是你比你想象的更需要“心里有道”；二是“行仁会吃亏”多半是想象出来的恐惧。对此刻的我，不必担心做个有原则的人会损失什么，真正损失的，是那些因为怕吃亏而不敢善良的瞬间。试一次就会发现，它没那么贵。
- 现有情境（scene，供参考风格，可改可不改）：你觉得“善良”“讲原则”会吃亏，正在纠结要不要继续的时候。
- 现有今日行动（practice，供参考风格）：今天做一件'亏一点但心安'的小事，记下真实的感受。

### id 421（《论语·卫灵公篇》| 标签：机会、担当、勇气、主动、争取）
- 原文：当仁，不让于师。
- 白话：面对仁义之事，就是对老师也不必谦让。
- 讲解（insight）：我们从小被训练「让」，久而久之把退缩当成了美德。孔子划了条线：涉及是非与担当的时刻，不让——哪怕是面对师长。机会当前假装不想要、任务面前等别人先举手、会场里明明有好想法却等「合适时机」，本质上都是把「当仁不让」的事做成了礼让。谦让留给利益，不让留给责任。该你上的那一刻，别用谦虚当挡箭牌。
- 现有情境（scene，供参考风格，可改可不改）：明明想要，却习惯性谦让、退后一步的时候
- 现有今日行动（practice，供参考风格）：今天在该发言的场合把第一句话说出口，不彩排到散会。

### id 422（《论语·卫灵公篇》| 标签：原则、变通、诚信、坚守）
- 原文：君子贞而不谅。
- 白话：孔子说：“君子坚守正道，但不拘泥于小信小节。”
- 讲解（insight）：“贞”是守住大方向，“谅”是不问对错的小信。孔子说，真君子守的是“贞”——大义、正道，不必为了一句小承诺把自己捆死。这不是教人说话不算话，而是说承诺也有大小之分：为守一个口头小约，去伤害更大的是非，不值。对此刻的我，答应之前先看大方向，答应之后能守则守；真遇到冲突，优先对得起的是那个大的，而不是那个一时面子上过不去的。
- 现有情境（scene，供参考风格，可改可不改）：你答应了一件事，后来发现它违背你更大的原则，左右为难的时候。
- 现有今日行动（practice，供参考风格）：今天翻出一条旧约定，若它已违背更大的原则，主动开口说明并调整。

### id 423（《论语·卫灵公篇》| 标签：职场、敬业、付出、回报、责任）
- 原文：事君，敬其事而后其食。
- 白话：孔子说：“侍奉君主，先认真把事情做好，再谈俸禄报酬。”
- 讲解（insight）：孔子说，先敬其事，再谈其食——先把事做漂亮，回报是后面自然会来的一件事。这话在今天听来像“老板画饼”，但换位想：没人愿意先给一个还没证明自己的人高薪。对此刻的我，纠结“凭什么我多干”之前，先看自己做的事够不够“敬”——够不够认真、够不够让人放心。认真本身是稀缺的竞争力，它带来的回报，往往不只体现在那一份工资上。
- 现有情境（scene，供参考风格，可改可不改）：你觉得“给多少钱干多少活”，却又因此和上司处得越来越僵的时候。
- 现有今日行动（practice，供参考风格）：今天把手头一件事多打磨一遍，做到不必返工再收手。

### id 424（《论语·卫灵公篇》| 标签：教育、公平、包容、机会、平等）
- 原文：有教无类。
- 白话：孔子说：“教育不分贫富贵贱、聪明愚笨，对所有人都一视同仁。”
- 讲解（insight）：孔子的“有教无类”，是说接受教育的门槛不该设限——不看出身、不看资质。这句话放今天，既是教育观，也是带人观：别用“ta不行”当借口，很多“不行”只是没遇到合适的教法和足够的耐心。对此刻的我，教孩子、带新人还是教自己，先放下先入为主的成见。被认真对待过的人，和被打发过的人，长出来的样子完全不同。
- 现有情境（scene，供参考风格，可改可不改）：你想教或带一个人，却觉得“ta这个基础，教了也白教”的时候。
- 现有今日行动（practice，供参考风格）：今天给一个你觉得'没救'的人换种讲法，先让他赢一小步。

### id 425（《论语·卫灵公篇》| 标签：分歧、价值观、人际、选择、放手）
- 原文：道不同，不相为谋。
- 白话：志向主张不同，就不必在一起谋划共事了。
- 讲解（insight）：这句话不是傲慢，是止损：目标不同的人强行同行，每一步都是内耗——你以为在合作，其实在互相矫正方向。更隐蔽的是「道不同」的关系消耗：你想要长期，他要短期；你想做产品，他要流量。判断标准很简单：和这个人深聊一次「到底为什么做这件事」，如果听得心里发凉，答案已经有了。好聚好散不是失败，是把彼此放回各自的道上。
- 现有情境（scene，供参考风格，可改可不改）：勉强维持一段三观不合的关系时
- 现有今日行动（practice，供参考风格）：今天把手头的合作分个类：道不同，还是节奏不同——前者想好体面的收尾。
