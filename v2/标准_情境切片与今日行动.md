# 论语小工具 v2 · 情境切片与今日行动 · 写法标准

> 2026-09-10 定稿。本文件是 v2 情境库「生成子智能体」与「审校子智能体」共用的唯一标准。
> 目标：506 章每一章产出 **3 个情境切片 + 3 条今日行动**，全部具体、有画面、贴合本章论语、可直接上线。

---

## 0. 一句话标准

**情境切片 = 让现代成年人一眼认出"这就是我"的具体处境；今日行动 = 今天就能做的一件小事。二者都必须从这一章的论语出发，不能写成别的章的内容。**

---

## 1. 情境切片（每章 3 条）

### 1.1 定义
一个现代成年人可能遇到的**具体处境**，半句话讲清，让用户一眼认出自己。不是格言、不是道理、不是情绪词。

### 1.2 写法要点（逐条对照）

| 要点 | 说明 | ✅ 好例 | ❌ 坏例 |
|---|---|---|---|
| **具体有画面** | 有场景、有人物处境、有细节 | 「一个加班到深夜、怀疑自己努力没有意义的人」 | 「一个迷茫的人」 |
| **半句话讲清** | 一句话内说清，不绕 | 「被老同学比下去、心里失衡的中年人」 | 「当你在人生的十字路口感到困惑和彷徨的时候」 |
| **是处境不是道理** | 描述"遇到什么事"，不是"应该怎样" | 「答应别人的事忘了做，被追问时才想起来」 | 「做人要讲诚信」 |
| **能认出自己** | 让目标用户（成年人，普通生活）觉得"这就是我" | 「想对父母好，却总是没说两句就吵起来」 | 「一个孝顺的人」 |
| **覆盖生活面** | 3 条之间尽量错开生活面（工作/家庭/待人/内心） | 一条工作、一条家庭、一条内心 | 三条全是职场 |
| **可对应论语** | 这条处境恰好能被本章这句论语点醒 | 本章「学而时习之」→「收藏了一堆课，从没真正用过」 | 本章讲学习，情境却是「夫妻吵架」 |

### 1.3 句式参考（不必拘泥，自然为好）
- 「一个……的人」（第三人称，像人物切片）
- 「当你……的时候」（第一人称处境）
- 可以带一点"钩子"：处境 + 内心的一下（「心里咯噔」的那个瞬间）

### 1.4 3 条之间
- 必须**互不相同**（不能是同义改写）。
- 尽量错开生活面（工作/家庭/待人/内心 至少覆盖 2 个面）。
- 3 条都要**真正贴合本章论语**——用户挑中任一条，点进去看本章原文都不违和。

## 2. 今日行动（每章 3 条）

### 2.1 定义
**今天就能做**的一件小事，把这一章的论语践行进今天的生活。不是道理、不是长期计划、不是"本周/三个月"的周期任务。

### 2.2 写法要点

| 要点 | 说明 | ✅ 好例 | ❌ 坏例 |
|---|---|---|---|
| **今天就能做** | 今天一天内可完成，不需要长期坚持 | 「今天把你收藏夹里囤的一门课，真打开听一节」 | 「坚持每天学习一小时」 |
| **具体可执行** | 有明确动作，知道第一步干什么 | 「今天主动给那个你欣赏的人发一句具体的话」 | 「多关心朋友」 |
| **贴合本章** | 由本章论语直接推出，不是泛泛的自我提升 | 本章「不念旧恶」→「写下那个你想起就堵的人，把最后一句怨言在心里说完，放下它」 | 本章讲放下旧怨，行动却是「今天去健身」 |
| **轻** | 小事、不吓人、没有压力 | 「给父母打一个电话，只问他们今天吃了什么」 | 「今天跟父母彻底和解，把二十年心结谈开」 |
| **不自欺** | 不写"多……""好好……"这类空词 | 「挑一件停在90%的事，只往前推一筐土」 | 「努力把每件事做好」 |

### 2.3 3 条之间
- 互不相同（不能是同义改写）。
- 可以是一个动作的不同切面（比如：说一句 / 写下来 / 做一个动作），但都要具体。
- 3 条都贴合本章。

---

## 3. 风格红线（生成与审校都要守）

1. **禁 AI 套话**：「众所周知」「不禁让人深思」「综上所述」「值得一提的是」「在这个……的时代」等一律禁止。
2. **禁说教腔**：情境切片不是劝诫，是处境；今日行动是"做一件事"，不是"你应该……"。
3. **禁空泛词**：「迷茫」「努力」「成长」「坚持」「心态」这类抽象词，除非有具体画面撑着，否则判不合格。
4. **贴合优先**：宁可写得朴素，不可为了漂亮跑题。
5. **不重复**：全库 506 章内，情境切片语义上不要大面积重复（同主题章允许相近生活面，但不能逐字雷同）。

## 4. 输出格式（子智能体统一遵循）

每章输出 JSON（追加到该批的产出文件）：

```json
{
  "id": 1,
  "scenes": [
    "……",
    "……",
    "……"
  ],
  "practices": [
    "……",
    "……",
    "……"
  ]
}
```

- 每个情境切片 / 今日行动是一句完整的话（不超过 ~40 字）。
- 输出文件按批写入：`v2_data/产出/批<N>/<原数据id>.json` 或合并成 `v2_data/产出/批<N>/batch.json`（由生成子智能体自定，但必须落盘、可被审校读取）。
