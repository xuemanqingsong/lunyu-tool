# 论语小工具 v2 · 情境库审校标准

> 2026-09-10 定稿。给「独立审校子智能体」用：只审不改，判决分级。
> 审校对象 = 各批子智能体产出的 506 章 × 3 情境切片 + 3 今日行动。

---

## 0. 审校岗位定位

- **只审不改**：不修改产出，只输出审校报告。每个问题给出具体位置（章 id + 第几条）+ 修改建议。
- **判决分级**（对每一章）：
  - **通过**：3 情境 + 3 行动全部合格，可直接上线。
  - **小改**：1-2 处局部问题（表述、重复、略抽象），给出具体改法。
  - **大改**：情境不贴合本章、跑题、空泛、或与其他章大面积重复，需要重写。

## 1. 审校前必读

1. `标准_情境切片与今日行动.md`（本岗位依据的写法标准）
2. `v2_data/` 下该批的输入（本章论语原文/白话/讲解/tags）
3. 待审产出

## 2. 情境切片四维

### 2.1 贴合（最重要）
- 这条情境**能不能被本章这句论语点醒**？
- 用户挑中这条，点进来看本章原文，会不会觉得"对上了"？——对不上 = 大改。
- 防张冠李戴：本章讲「学而时习」，情境却写「夫妻吵架」，判大改。

### 2.2 具体
- 有画面、有处境、有细节，不是抽象词（迷茫/努力/成长/心态……无画面支撑即不合格）。
- 半句话讲清，不绕。

### 2.3 能认出自己
- 是"现代成年人的真实处境"，不是格言、不是道理、不是古代典故（不写"像颜回那样"）。
- 让人"咯噔"一下。

### 2.4 章内不重复
- 一章 3 条互不相同，不能是同义改写。
- 3 条尽量错开生活面（工作/家庭/待人/内心 ≥2 个面）。

## 3. 今日行动三维

### 3.1 今天能做
- 今天一天内可完成，不是"坚持/每周/三个月"的周期任务。
- 不是空泛的"多……""好好……"。

### 3.2 具体
- 有明确动作，知道第一步干什么。

### 3.3 贴合本章
- 由本章论语直接推出，不是泛泛的自我提升（本章讲放下旧怨，行动不能是"今天健身"）。

## 4. 全局性检查（审校每一批时都要注意）

- **库内重复**：这条情境/行动是否与**本批其他章**（或明显与已知全库主题）大面积雷同？
- **风格红线**：AI 套话、说教腔、空泛词（见写法标准 §3）。

## 5. 输出格式

审校报告写入 `v2_data/审校/批<N>_审校.md`，格式：

```
# 审校报告 · 批<N>
## 总结论：通过 N 章 / 小改 M 章 / 大改 K 章
## 逐章结论
- [id 1] 通过 / 小改（第2条情境略抽象，建议改为……）/ 大改（第1条情境与本章不贴合……）
## 最需要返工的问题（前5条，全局性的）
```

最终回复只返回：报告路径、总结论、最需要返工的 3 个问题（≤5 行）。
